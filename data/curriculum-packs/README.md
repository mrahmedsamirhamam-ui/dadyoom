
# محرك حزم المناهج في ضاديوم

المسار المرجعي:

`الدولة ← السنة الدراسية ← المنهج ← المرحلة ← الصف ← الفصل ← المادة ← الوحدة ← الدرس`

- لا ننشر حزمة غير موثقة.
- لا ننسخ كتابًا محميًا كاملًا دون ترخيص.
- ترتيب الدروس والوحدات يأتي من مصدر منهجي موثوق.
- الشرح والأنشطة والأسئلة داخل ضاديوم أصلية أو مرخصة.
- الاستيراد يحافظ على الدروس الغنية والأسئلة الموجودة ولا يعمل delete/reinsert للتاريخ.
- كل درس منشور يجب أن يحتوي محتوى كافيًا و3 أسئلة على الأقل.

فحص حزمة دون كتابة:
`node scripts/import-curriculum-pack.mjs --pack data/curriculum-packs/<pack>.json`

**تحديث أمان الاستيراد (2026-10-25):** لن ينشر الأمر `--apply` وحده أي حزمة. يلزم توثيق موافقة تحريرية على فهرس الفصل الحالي (`rights.officialTocVerified=true`) ومصدر HTTPS موثوق `rights.sourceUrl` وروابط وصفحات كل درس، ثم استخدام `--approve-reviewed-publish` إضافة إلى `--apply`. يتوقف الاستيراد قبل أي كتابة إذا كان توثيق المصدر ناقصًا. كما يقرأ النسخة الاحتياطية لكل الجداول كاملة، بصفحات ID مرتبة وعدّ نهائي متسق، ويمنع النسخ المبتورة ويكتب ملف النسخة محليًا بصلاحيات مقيدة. هذه الشروط احترازية ولا تحل محل مراجعة بشرية للمناهج أو اختبار الاستعادة الفعلي؛ لا تستورد إلى الإنتاج قبل الموافقة والتحقق.

استيراد حزمة بعد التحقق:
`node scripts/import-curriculum-pack.mjs --pack data/curriculum-packs/<pack>.json --apply`

## معيار ضاديوم للفهم القرائي والتعلّم المتحقق

**الحالة:** متطلب تربوي معتمد للتطوير والاختبار؛ توثيقه لا يعني تطبيقه برمجيًا أو توافره في جميع الدروس المنشورة.

**المبدأ:** لا تكفي طلاقة نطق الكلمات ولا حفظ الإجابات للحكم بتحقق التعلّم. تسعى ضاديوم إلى قياس الفهم، وتشخيص الصعوبات، وتقديم دعم متدرج، ثم إعادة القياس بنص أو نشاط جديد.

### دورة التعلم داخل درس القراءة

1. **قبل القراءة:** تنشيط المعرفة السابقة، وتوضيح هدف القراءة، وتوقع محتوى النص.
2. **أثناء القراءة:** تدريب مناسب على القراءة، وتوضيح المفردات من السياق، وتحديد الفكرة الرئيسة والعلاقات بين الأفكار.
3. **بعد القراءة:** أسئلة للفهم المباشر والاستنتاجي والنقدي والتعبير بلغة الطالب، مناسبة لعمره وصفه.
4. **التشخيص:** فصل مؤشرات دقة القراءة والطلاقة عن الفهم والتعبير؛ تحديد المهارة التي تشير إليها إجابات الطالب دون إصدار تشخيص طبي أو تصنيف دائم للطفل.
5. **التدخل:** شرح بديل وتدرج في الصعوبة وأنشطة فردية مناسبة؛ إبقاء دور المعلم في المراجعة والتعديل.
6. **إعادة التحقق:** نص موازٍ أو مهمة جديدة تقيس نقل المهارة، مع تسجيل الفرق بين القياسين وعدم الاكتفاء بإعادة السؤال نفسه.

### معايير قبول الدرس

- محتوى أصلي أو مرخص ومتوافق مع أهداف منهج موثق، لا مجرد عنوان أو نص بلا شرح.
- هدف واضح للفهم القرائي ومفردات وأنشطة قبل القراءة وأثناءها وبعدها عند ملاءمة نوع الدرس.
- أسئلة تقيس مستويات فهم متنوعة، وإجابات مفسرة وتغذية راجعة علاجية؛ لا الاكتفاء بصواب/خطأ.
- إتاحة القراءة الصوتية أو بدائل الوصول حين تتوفر، وتصميم متوافق مع الهاتف والفروق الفردية.
- عرض تقدّم قابل للفهم للمعلم وولي الأمر مع ضوابط حماية بيانات الأطفال، وقياس منفصل للطلاقة والفهم والتعبير حيث تتوفر أدوات قياس موثوقة.
- مراجعة بشرية لعينة من الدروس والنتائج قبل الادعاء بأن النظام يحسّن الفهم أو يقيسه بدقة.

**الأولوية التنفيذية:** إكمال الدروس الرسمية الناقصة للبحرين وجميع الدول العربية الـ22 أولًا، وتطبيق هذه الدورة تدريجيًا داخل الدروس أثناء استكمالها، دون إرجاء نشر المحتوى الصحيح من أجل ميزات ثانوية. لا خدمات مدفوعة دون موافقة.
