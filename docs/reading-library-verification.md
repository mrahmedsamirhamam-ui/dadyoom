# مكتبة ضاديوم — سجل التحقق وبوابة الاعتماد
التحديث: 2026-11-11. النطاق: الفرع `feature/reading-library-foundation-20261111` وPR #146 فقط.

## التغييرات المؤكدة في الفرع
- منع الاعتماد باستخدام بيانات localStorage المزوّرة؛ الملاحظات محلية ولا تُعتمد تلقائيًا.
- رفض الكتب المجهولة والمدخلات التالفة والمكررة والملاحظات الطويلة.
- إظهار الجوازات الخمسة وفق التقدم المحلي المحسوب دون شهادات أو اعتماد رسمي.
- بقاء الكتابين بحالة «غير متحقق منه» ودون نصوص كاملة أو أسئلة منشورة.
- التحقق من معرّفات أسئلة الفهم الفريدة وغير الفارغة، ووجود اسم المراجع.
- إضافة اختبارات حدود 0–50 كتابًا وحالات العبث بالبيانات.

## أوامر التحقق المطلوبة في نسخة معزولة من الفرع
```bash
npm ci
npx vitest run lib/reading-library/books.test.ts lib/reading-library/local-progress.test.ts lib/reading-library/passports.test.ts
npx tsc --noEmit
npx eslint app/library/page.tsx components/library/LocalReadingPanel.tsx lib/reading-library
```
**الحالة:** لم تُشغّل هذه الأوامر في بيئة المشروع في جلسة التعديل؛ لا تُسجل PASS دون سجل تشغيل فعلي. لا توجد نتائج CI مؤكدة على آخر Commit وقت إعداد هذا السجل.

## تحقق يدوي مطلوب
1. فتح `/library` على هاتف صغير واتجاه RTL؛ فحص العناوين، بطاقات الكتب والجوازات.
2. حفظ ملاحظة ثم إعادة تحميل الصفحة؛ تأكيد بقائها على الجهاز فقط.
3. تعطيل التخزين المحلي؛ التأكد من رسالة خطأ مفهومة وعدم ادعاء الحفظ.
4. تعديل `approved: true` يدويًا في localStorage؛ التأكد من بقاء العداد صفرًا.
5. التأكد من عدم عرض نص كامل أو اعتماد أو شهادة أو أسئلة مختلقة.

## ضوابط الاستمرار
- لا تعديل للمنصة الحية أو مشاريع المدارس الستة.
- لا قواعد بيانات أو migrations أو حسابات أو AI أو خدمات مدفوعة.
- لا دمج ولا نشر. PR #146 يبقى Draft حتى ظهور أدلة الاختبارات وفحص الحقوق والمراجعة البشرية.
- لا تتحول «مؤهلية الكتاب» إلى «اعتماد قراءة» دون تحقق بشري موثوق.
