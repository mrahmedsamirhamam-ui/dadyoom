# ضاديوم — مصفوفة اختبار المباحث والمكونات
تاريخ الإعداد: 2026-11-12. الحالة: خطة فحص؛ لا نتائج PASS قبل تشغيل فعلي.

## فحوص آلية قابلة للتشغيل
| النطاق | الأمر | ما الذي يثبته | ما الذي لا يثبته |
|---|---|---|---|
| حزم المناهج | `npm run curriculum:verify` | صحة البنية وفق المدقق الحالي | التطابق الرسمي مع كتاب الوزارة |
| تغطية المناهج | `npm run curriculum:coverage` | تقرير التغطية وفق البيانات المتاحة | اكتمال شرح كل درس |
| اختبارات الوحدة | `npm run test:run` | اجتياز الاختبارات المكتوبة | سلامة كل شاشة ومسار |
| TypeScript | `npx tsc --noEmit` | أخطاء الأنواع القابلة للاكتشاف | سلامة التشغيل |
| تدقيق المصدر | `npm run release:audit` | فحوص المصدر المبرمجة | اختبار أمان قاعدة حية |
| تدقيق MVP | `npm run release:final-audit` | متطلبات المصدر المبرمجة | جاهزية النشر الفعلية |
| البناء | `npm run build` | إمكانية بناء التطبيق في بيئة الفحص | تشغيل كل ميزة مع خدماتها |

يمكن تشغيل الفحوص من GitHub Actions: `Education modules verification (manual, no deploy)` على فرع المكتبة. لا توجد خطوة نشر أو دمج أو كتابة إلى قاعدة بيانات في ملف سير العمل.

## حالات قبول تحتاج متصفحًا وحسابات اختبار معزولة
| المبحث / المكوّن | سيناريو الاختبار | دليل القبول |
|---|---|---|
| اختيار الدولة والصف | تغيير الدولة والصف ثم فتح المنهج | قائمة الدروس الصحيحة وعدم تسرب بيانات دولة أخرى |
| اللغة العربية | فتح درس حقيقي ومراجعة الشرح والأنشطة والتقويم | ظهور المحتوى الكامل وليس الأهداف فقط |
| الرياضيات | فتح درس وتمرين والتحقق من التصحيح | أسئلة وحلول متسقة مع الدرس |
| العلوم | فتح شرح وصورة/فيديو/تجربة | الوسائط تعمل أو تظهر رسالة فشل واضحة |
| الدراسات الاجتماعية | فحص درس ومصدره والخرائط | توثيق المصدر وعدم ادعاء مطابقة غير مثبتة |
| التربية الإسلامية | فحص النصوص والأنشطة | مراجعة علمية وتربوية بشرية |
| اللغة الإنجليزية / غير الناطقين | اختبار الفيديو والصوت والاتجاه | وسائط تعمل وتوجيه لغوي صحيح |
| الألعاب التعليمية | تشغيل اللعبة وإنهاؤها | قواعد وتغذية راجعة مفهومة لا مجرد مؤثرات |
| عروض الدروس | فتح العرض والتنقل | لا صفحات فارغة أو تعطل |
| ضاد داخل الدرس | سياق السؤال والإجابة والصلاحيات | عدم تسرب بيانات وعدم ادعاء محتوى غير موجود |
| الحسابات والأدوار | دخول الطالب/المعلم/ولي الأمر/المدرسة | عزل الصلاحيات والبيانات باختبارات حقيقية |
| المكتبة والجوازات | ملاحظات محلية ومحاولات تزوير الاعتماد | عدم اعتماد الكتب دون تحقق بشري |

## آلية تسجيل الإخفاق
لكل مشكلة: الدولة، الصف، المبحث، رابط الدرس، البيئة، خطوات إعادة الإنتاج، النتيجة المتوقعة والفعلية، أول خطأ مثبت، لقطة أو سجل منقّح، Issue/Commit، تصنيف كود/بيئة/محتوى، أصغر إصلاح آمن، وإعادة الاختبار.

## بوابات الأمان
- هذا الملف لا يعني أن الاختبارات نُفذت أو نجحت.
- لا تغييرات في الإنتاج، ولا migrations، ولا حسابات حية، ولا نشر أو دمج.
- لا تُحوّل نتائج فحص البنية إلى ادعاء مطابقة رسمية للمناهج.
- لا مساس بمشاريع المدارس الستة.
