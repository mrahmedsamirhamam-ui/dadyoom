**تنبيه حاسم:** العدد «468 منشورًا» المذكور في التكليف ليس العدد الكلي الحالي في قاعدة ضاديوم. يحتمل أنه نطاق خاص، ولم يُعثر على تعريف نطاقه. لا يُستخدم لقرارات جماعية أو نسب شمول.

**تفسير الأرقام:**
- نقص الأنواع الأربعة في `lesson_activities` دليل *تصنيفي فقط*، ولا يثبت غياب المهارة تمامًا؛ قد يكون الشرح أو الصوت أو نشاط آخر خارج الجدول.
- لا يوجد حقل معياري مُتحقق منه يميز تقييمًا قبليًا أو بعديًا لكل درس؛ عدم وجود وسم خاص لا يساوي عدم وجود أسئلة قبليّة أو بعديّة داخل المحتوى.
- **الدروس بلا تسجيل صوتي: غير متحقق منه.** جدول `lesson_videos` ليس سجلًا للصوت، و`audio_text` ليس دليل تسجيل صوتي. يلزم جرد وسائط وربط آمن بالدروس وتشغيل عينات.
- **التغطية الفعلية للمهارات الأربع: غير متحققة.** لا يُعتمد رقم الأنواع الأربعة نسبة أداء.
- حالات المراجعة المعتمدة فعليًا: **غير متحققة** لأن جداول المراجعة الجديدة لم تُطبق. بعد تطبيق الترحيل بمعزل وتحقق، يفسر النظام السجل المنشور الذي بلا قرار مراجعة على أنه «منشور — لم يُراجَع»، دون تحديثه أو إخفائه.

## 2. ما فُحص من الشيفرة
- `app/admin/lessons/page.tsx`: يعتمد على `lessons.status` للأرشفة والنشر، ولا يُمثل مراجعة المحتوى.
- `app/admin/curriculum/source-review/page.tsx`: قائمة مصادر إدارية منفصلة؛ لا تُعد بديلًا للبطاقة ذات المحاور الستة.
- `app/admin/layout.tsx`: يستخدم `profiles.role=admin`؛ هذا غير كاف وحده لاتخاذ قرارات الاعتماد في ضوء قضايا تصعيد الأدوار. تضاف بوابة مستقلة fail-closed تتطلب `auth.user.app_metadata.dadyoom_lesson_reviewer===true` ووجود ملف إداري باسم حقيقي.
- `app/api/dad/chat/route.ts` على `main`: نموذج المساعد يتلقى `lessonContent` و`pageContext` من جسم طلب العميل، ويمكن أن يُعيد صياغة الرد عبر مزود جودة عند ضعف العربية دون تضمين سياق الدرس في طلب الإصلاح. ليست هذه مصادر موثوقة بذاتها. يستخدم `routeAi` و`consumeFeature`، ولم يُستدع مزود فعلي في هذا التدقيق.

## 3. ما أُعد للتطبيق بعد الاعتماد فقط
- ترحيل `supabase/migrations/20261109200700_lesson_review_quality_phase1.sql`: حالات مستقلة عن النشر العام، ملاحظات ومحاور جودة وسجل قرارات وإصدارات، ولوحة استعلام داخلية. لم تُطبق SQL على الإنتاج.
- `app/admin/quality` و`/admin/quality/[id]`: قائمة فلترة البلد والصف والحالة، بطاقة المحاور وسجل القرارات، متاحة حصريًا لمراجع مُنح علمًا إداريًا في `app_metadata`. إن غابت الجداول يظهر خطأ صريح لا بيانات وهمية.
- `app/api/admin/quality/route.ts`: قرارات يدوية فقط من مراجع مصادق عليه، ورفض تخطي المراحل وتوثيق الاسم والتاريخ والملاحظات داخل SQL.
- `lib/lesson-review/model.ts`: شارة الزوار معطّلة صراحة `PUBLIC_REVIEW_BADGE_ENABLED=false`. لا يوجد أي مكون زائر يستعمل الشارة.
- لم تُعدّل `lessons.status` أو `app/lessons` أو ملفات SEO أو الأسماء البديلة أو الإنجليزية أو إعلانات المجانيين.

**ملاحظة إصدارات:** تُلتقط نسخة من سجل الدرس عند *كل انتقال مراجعة*، ولا يراقب هذا المسار بعدُ كل تعديل خارجي على محتوى `lessons`. لذلك لا يوصف بأنه أرشيف كامل لكل تحرير تاريخي. يجب اعتماد مسار تحرير موحد قبل ضمان أرشفة جميع التعديلات مستقبلًا.

## 4. اختبار ضاد: 100 سؤال
- `data/qa/dad-arabic-100.json`: 100 سؤال في عشرة مجالات، ومفتاح إجابة أولي لكل سؤال. **جميع الإجابات تحمل «تحتاج مراجعة معلم لغة»، ولا واحدة معتمدة.**
- `scripts/dad-arabic-benchmark.mjs`: افتراضيًا **Dry run** بلا اتصالات أو تكلفة؛ `--execute` على نطاق محلي أو بيئة staging صريحة مع جلسة اختبار مصادق عليها فقط.
- نسبة المطابقة النصية إن شُغلت = مؤشر تشخيصي أولي، **وليست نسبة صحة لغوية معتمدة**، لأن التعبير قد يختلف عن النص المرجعي مع صحة المعنى أو العكس.
- لم تُرسل الأسئلة إلى ضاد فعليًا، ولا يوجد معدل صواب مُقاس حتى الآن.
- **اقتراح غير مفعّل:** عند وجود `lessonId` يجلب الخادم النص المنشور المصرح به من قاعدة البيانات، يحدده مصدرًا أول، يرفض السياق الوارد من العميل، ويطلب من المساعد قول «لم أجد الجواب في هذا الدرس» عند غياب الدليل. يلزم اختباره ضد حقن التعليمات والمحتوى غير الموثق وقيود المصادقة والرصيد قبل تفعيله.

## 5. بوابة الجودة وNO_GO
**لم يُشغّل npm test أو TypeScript أو ESLint أو Next build لهذا الفرع بعد،** لأن بيئة التنفيذ هنا لا تتضمن نسخة محلية من المستودع وتعجز عن الوصول لشبكة GitHub؛ إنشاء الملفات عبر الموصل لا يساوي تنفيذ CI. جرى تدقيق بنيوي محدود للترحيل والبيانات من جهة أدوات الكتابة، وليس بديلًا للاختبارات.

أوامر يجب تشغيلها على checkout معزول لهذا الفرع، بعد كل دفعة وبلا نشر:
```bash
node --test tests/dad-arabic-qa.node.test.mjs
node scripts/dad-arabic-benchmark.mjs
npx vitest run tests/lesson-review-model.test.ts
npx tsc --noEmit
npx eslint lib/lesson-review app/admin/quality app/api/admin/quality tests/lesson-review-model.test.ts
npm run build
```
قبل تطبيق الترحيل في **staging المعزول**: فحص SQL/RLS، وتأكد أن anon/authenticated لا يقرؤون سجلات الجودة أو يستدعون RPC، واختبار المراجع الحقيقي بصلاحية موقّعة، ورفض القفز والتعديل بعد الاعتماد. أي فشل يبقي NO_GO.
