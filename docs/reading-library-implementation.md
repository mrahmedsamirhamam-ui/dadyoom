# مكتبة ضاديوم العالمية — خطة التنفيذ المرحلية
تاريخ الإنشاء: 2026-11-11
الحالة: تصميم تنفيذي قيد المراجعة؛ **غير منشور**.

## النطاق
- مكتبة متعددة الأعمار (طلاب الصفوف 1–12، المعلمون، أولياء الأمور، والقراء الكبار).
- فهرسة كتب مرخّصة أو في الملكية العامة؛ الكتاب الخارجي يُسجَّل ببيانات وصفية دون نسخ النص.
- قارئ إلكتروني للمحتوى المصرّح بنشره فقط.
- خمسة جوازات تدريبية، عشرة كتب لكل جواز، 50 كتابًا في المسار؛ لا تستخدم شعار المسابقة أو تدعي إصدار جواز رسمي.
- تلخيص أصيل يكتبه الطالب، مع تغذية راجعة وأسئلة فهم ومناقشة ومحاكاة تحكيم تدريبية غير رسمية.
- لوحات تقدم للطالب والمعلم وولي الأمر مع صلاحيات معزولة.

## نموذج البيانات المقترح (يُراجع قبل أي migration)
1. library_books: id, title, author, language, age_min, age_max, category, rights_status, rights_evidence, content_url_nullable, published_at.
2. reading_entries: id, reader_id, book_id_nullable, external_book_title_nullable, started_at, completed_at_nullable, verification_status.
3. reading_summaries: id, entry_id, author_id, body, created_at, revised_at, feedback_json.
4. reading_questions: id, book_id, skill, question_text, answer_rubric, source_provenance, reviewed_at.
5. reading_attempts: id, entry_id, reader_id, question_id, answer, score_nullable, evaluated_at.
6. reading_passports: id, reader_id, stage (1..5), status, approved_at_nullable, reviewer_id_nullable.
7. reading_audit_events: actor_id, action, target_type, target_id, created_at.

## قواعد الأمان
- RLS لجميع الجداول التي تضم بيانات شخصية، وسياسات SELECT/INSERT/UPDATE مستقلة، ومنع المستخدم من اعتماد إنجازه أو تعديل تقييم المعلم.
- تحقق أدوار المعلم/ولي الأمر من عضويات موثوقة على الخادم؛ لا ثقة في role من طلب العميل.
- الكتب الخاصة والملخصات وبيانات الأطفال غير عامة؛ لا قوائم تصنيف عامة بأسماء الأطفال.
- فحص تراخيص الكتب وإثبات مصدر الحقوق قبل إتاحة نص كامل أو تنزيل.
- لا مفاتيح service-role في المتصفح؛ ضوابط معدل الطلبات وتكلفة الذكاء الاصطناعي.
- لا يتولى الذكاء الاصطناعي كتابة الملخص النهائي نيابة عن الطالب.

## مراحل التنفيذ
### المرحلة A — فحص الموجود
افحص بنية Next/React الفعلية، مسارات /study و auth، نماذج Supabase وسياسات RLS، الميزات الحالية، إعدادات Cloudflare، الاختبارات، وتعارضات PR المفتوحة. لا تكرر الوظائف الموجودة.
### المرحلة B — MVP معزول
كتالوج قابل للبحث والتصفية، صفحة كتاب، إضافة كتاب خارجي، دفتر قراءة، ملخص الطالب، أسئلة مراجعة معتمدة، حساب تقدم الجوازات الخمسة، واجهة عربية RTL للجوال.
### المرحلة C — تدريب ذكي
إرشاد «ضاد» لكتابة ملخص الطالب، أسئلة مقيدة بالنص المصرح به، فحص هلوسة المخرجات، حدود استخدام وكاش، تقييم بشري عند الحاجة.
### المرحلة D — لوحات وشهادات
لوحة معلم/ولي أمر مع تحقق علاقات وصلاحيات، تقارير PDF، شهادات داخلية باسم ضاديوم فقط، ومحاكاة مقابلة.
### المرحلة E — اختبار ونشر
اختبارات unit/integration/E2E وRLS بحسابات مدرسيتين معزولتين، WCAG، الأداء على الجوال، فحص حقوق المحتوى. نشر تجريبي ثم اعتماد نشر الإنتاج بعد نتائج موثقة.

## معايير القبول
- لا يمكن لقارئ الوصول إلى ملخصات قارئ آخر أو تعديل درجة تقييم.
- لا يُحتسب كتاب بمجرد فتحه؛ يتطلب ملخصًا أصيلًا وتحققًا من المعايير.
- لا تتجاوز المرحلة 10 كتب معتمدة، ولا يتكرر نفس الكتاب في الجوازات.
- تعمل صفحات المكتبة على الجوال RTL، مع حالات فارغة وتحميل وخطأ واضحة.
- لا عرض لنص محمي دون سند ترخيص.
- لا نشر ولا دمج قبل اجتياز الاختبارات والمراجعة.

## حدود هذه الدفعة
هذا الملف يثبت النطاق والمعايير فقط، وليس ادعاء بتنفيذ المكتبة أو نشرها.
