# مكتبة ضاديوم — حدود النسخة المصغرة وخطة مستقبلية مؤجلة
التاريخ: 2026-11-11. الحالة: فرع تجريبي غير منشور؛ PR #146 مسودة.

## المسموح الآن
- واجهة عربية RTL لتعريف المكتبة ومسارات القراءة.
- فهرس مؤلفات صاحب المشروع فقط؛ الحقوق غير المثبتة تُوسم «غير متحقق منه»، ولا تُنشر النصوص الكاملة.
- ملاحظات القراءة محليًا في المتصفح، دون حسابات أو بيانات شخصية.
- خمسة جوازات تدريبية: عشرة كتب مختلفة معتمدة لكل جواز، بحد أقصى 50 كتابًا.
- أسئلة فهم قصيرة (2–3) يكتبها المؤلف أو يراجعها معلم، فقط بعد توفرها فعليًا.
- لا يعتمد الكتاب تلقائيًا بمجرد كتابة إجابة؛ لا توجد حاليًا آلية تحقق بشرية موثوقة، لذا تبقى الاعتمادات صفرًا.
- اختبار حالات البيانات المحلية المزوّرة والتكرار والحدود، والتحقق من واجهة الجوال.

## مؤجل — ليس إذنًا بالتنفيذ
أي قواعد بيانات أو migrations أو RLS جديدة، حسابات القراء، مزامنة التقدم، لوحات المعلم أو ولي الأمر، الأسئلة المولّدة بالذكاء الاصطناعي، المدرب الصوتي، المقابلات الآلية، المنافسات الجماعية، التحليلات المتقدمة، الشهادات، وأي دمج أو نشر.

## بوابة القبول
يلزم توثيق حقوق الإتاحة، وإضافة أسئلة مراجَعة حقيقية، وتصميم تحقق بشري موثوق من الإجابات، وتشغيل الاختبارات وتوثيق نتائجها قبل التفكير في الاعتماد. تبقى بوابة الدمج والنشر مغلقة. لا تُمس مشاريع المدارس الستة.
