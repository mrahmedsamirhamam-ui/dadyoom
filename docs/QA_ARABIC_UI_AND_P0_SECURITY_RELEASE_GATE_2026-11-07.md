# ضاديوم — بوابة الجودة اللغوية والأمنية (7 نوفمبر 2026)

**الحالة:** تغييرات على فرع منفصل للمراجعة والاختبار. لا نشر على الموقع، ولا تغيير في قاعدة الإنتاج.

## قائمة التصحيحات اللغوية

| الواجهة | الخطأ أو العبارة السابقة | الصياغة الجديدة |
| --- | --- | --- |
| المعلم | {عدد الفصول} فصل | رقم + صيغة فصل/فصلان/فصول/فصلًا |
| الطالب | X من Y دروس مكتملة | X درسًا من أصل Y درسًا، بحسب العدد |
| المدرسة | N معلم / N طالب / N فصل | رقم + صيغة معلم/طالب/فصل الصحيحة |
| المدرسة | X من Y نتيجة | رقم + صيغة نتيجةً/نتائج/نتيجة |
| المدرسة | N عاجل / N إيجابي / N مفتوح | تنبيهات عاجلة: N / مؤشرات إيجابية: N / إجراءات مفتوحة: N |
| بوابة المناهج | بلا حدّ 6 دروس | دون اقتصار على ستة دروس |
| ولي الأمر | إجمالي XP | إجمالي نقاط الخبرة |
| الرئيسية | اختبر الأزرار الآن / افتح شات ضاد | جرّب أدوات التعلم / اسأل ضاد |
| الرئيسية | شعار غير سلس | العربية تجمعنا، والمعرفة توسّع آفاقنا |

ملف التصريف الموحد: lib/arabic/counts.mjs وتعريفاته: lib/arabic/counts.d.mts. أمثلة التحقق: 1 صف، 2 صفان، 3 صفوف، 10 مهارات، 12 صفًا، 22 درسًا، 12 نتيجةً. تمييز 11–99 مفرد منصوب؛ 100 فأكثر صيغة مفردة محايدة لعداد الواجهة فقط. لا يستخدم هذا المختصر لإنشاء جمل حرة تحتاج إعرابًا تفصيليًا.

**لم يكتمل بعد** التدقيق البشري لجميع نصوص المنصة؛ تعدد الملفات والمسارات لا يثبت صفر أخطاء مطلقًا.

## Issue #117 — أدوار الحسابات

- lib/auth/profile-role-policy.mjs: دور محفوظ لا يتغير بطلب العميل. إنشاء teacher/school/admin يتطلب موافقة خارج التسجيل الذاتي.
- app/api/auth/complete-profile/route.ts: الاعتماد على getUser() وملف قاعدة البيانات، فشل مغلق على قراءة خاطئة، تعديل الاسم والدولة فقط لدور قائم، INSERT دون UPSERT لمنع السباق.
- app/auth/callback/route.ts وapp/api/auth/oauth-intent/route.ts: رفض نية OAuth لامتيازات مرتفعة دون اعتماد؛ الحفاظ على الدور المخزن.
- components/auth/EmailPasswordAuthForm.tsx وProfileOnboardingForm.tsx وapp/onboarding/page.tsx: منع الكتابة المباشرة إلى profiles ومنع اعتماد user_metadata.role كصلاحية.
- proxy.ts: حراسة أولية لنطاقات API admin/teacher/school/parent/student/child. الحماية داخل المعالج وRLS مطلوبة أيضًا.
- docs/security/STAGING_ONLY_PROFILE_ROLE_GUARD_ISSUE_117.sql: مرشح حماية في قاعدة اختبار فقط ضد UPDATE/INSERT المباشر الذي يتجاوز التطبيق؛ لم يطبق على الإنتاج.

التحقق المطلوب: JWT طالب يحاول PATCH لدوره إلى teacher/school/admin، وPOST ملف مميز مباشرًا = رفض؛ تعديل الاسم والدولة = سماح؛ موافقة مدير حقيقي من مسار داخلي موثوق = سماح. اختبار عزل بيانات المعلمين والمدارس وأولياء الأمور مع أكثر من حساب.

## Issue #57 — مفاتيح الإجابات والدرجات

- lib/security/answer-payload.mjs: لا يقبل سوى questionId وselectedAnswer؛ أي userId أو grade أو isCorrect أو answer key في طلب المتصفح مرفوض.
- app/api/questions/answer/route.ts: جلب المفتاح من الخادم، فحص الطالب وظهور الدرس عبر RLS، وتصحيح وحفظ درجة مشتقة من الخادم لا من المتصفح.
- app/api/assessments/check/route.ts: تم إيقاف المسار القديم الذي كان يقبل modelAnswer من العميل ويحفظ درجات؛ أصبح يرفض التصحيح غير الموثوق (HTTP 409) بلا أي كتابة حتى بناء تصحيح خادمي بمراجع موثقة. هذا الإيقاف قد يتطلب تعديل الشاشة القديمة قبل الاعتماد.
- docs/security/STAGING_ONLY_QUESTION_PRIVILEGES_ISSUE_57.sql: نموذج سحب SELECT المباشر للمفتاح وINSERT/UPDATE/DELETE لمحاولات الطالب من authenticated في بيئة اختبار. لا يطبق مباشرة قبل نقل كل القراء ومحرري المعلم وإثبات التراجع.

## معايير الإطلاق

1. اجتياز اختبارات Node والعقود ثم npm ci وTypeScript وESLint على فرع الاختبار.
2. مراجعة بشرية لغوية لواجهات الأطراف الأربعة على أجهزة حقيقية مع الحالات 0/1/2/3/10/11/12/21/22/100.

4. اختبار رحلة طالب في Cloudflare preview مستقل: تعلم، إجابة، حفظ، تحديث، استئناف، إعادة تسجيل دخول، تحقق من الدرجات والتقدم.
5. معالجة Issue #46 (النشر) وIssue #109 (تطابق سجلات التقدم)، وعدم الحذف الآلي للبيانات القديمة.

**STOP-SHIP:** إصلاحات SQL لم تختبر أو تنفذ على الإنتاج، ولم تُجر اختبارات JWT وعدّادات الجوال وCloudflare E2E الفعلية بعد؛ لذلك لا يجوز ادعاء جاهزية إنتاج 100%.
