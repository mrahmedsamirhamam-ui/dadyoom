
# ضاديوم — بوابة الإطلاق

لا تعتبر النسخة منشورة إلا بعد نجاح جميع هذه البوابات:

1. TypeScript.
2. ESLint بصفر أخطاء وصفر تحذيرات.
3. الاختبارات الآلية.
4. Production Build.
5. فحص Curriculum Packs.
6. فحص رحلة التعلم.
7. فحص المصدر النهائي.
8. Smoke Test على خادم Production محلي.
9. ضاد يرد فعلاً عبر المسار الحقيقي.
10. المسارات المحمية ترفض الزائر غير المسجل.
11. Google Provider مفعّل فعليًا، وليس مجرد زر في الواجهة.
12. عدم وجود أسرار أو Backups في Git.
13. robots وsitemap وmanifest تعمل.
14. نجاح git diff --check.
15. Commit وPush لا يحدثان قبل نجاح ما سبق.

## ما لا يفعله الكود وحده

- إنشاء Google OAuth Client داخل حساب Google Cloud.
- شراء أو اختيار الدومين.
- ربط الدومين بخدمة الاستضافة.
- إثبات ملكية الموقع داخل Google Search Console.

هذه إعدادات حسابات خارجية، لكنها شروط إطلاق وليست Features جديدة.
