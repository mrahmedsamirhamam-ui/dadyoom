## الحقيقة المثبتة حاليًا في ملفات المستودع

- سجل `arab-countries.json` يسجل **22 دولة**، لكنه سجل نطاق عمل، وليس دليل تغطية الكتب.
- توجد حزمة محلية واحدة في `data/curriculum-packs`: `bh-2026-arabic-primary-g1-s1.json`.
- الحزمة تخص **الصف الأول بالبحرين، الفصل الأول**، وتحتوي 3 وحدات و**18 سجل درس**.
- خاصية `rights.verified=true` تعبر عن إثبات حقوق/مصدر في بنية الحزمة، ولا تعني أن قائمة موضوعاتها راجعها مراجع مع فهرس الوزارة.
- `rights.sourceUrl` غير محدد، وكذلك `source.url` لكل سجل من الدروس الثمانية عشر. أرقام الصفحات الموجودة لا تكفي وحدها لإثبات مطابقة طبعة 2026–2027.
- مصفوفة التخطيط تحسب **132 خانة افتراضية** = 22 دولة × 3 صفوف × فصلين. ليست إقرارًا بأن جميع الدول تعتمد فصلين فقط؛ غرضها إبراز الفجوات وبدء العمل.
- **خانة واحدة فقط** لها حزمة محلية في هذا الدليل، بينما **131 خانة** بلا حزمة محلية. لا يعني ذلك عدم وجود دروس منشورة في Supabase، بل عدم وجود ملفات حزم من هذا النوع في المستودع.
- لا توجد إلى الآن نسبة تغطية رسمية قابلة للحساب من هذه الحزم. تُترك `officialCoveragePercent=null` و`officialTextbookTocMatch=NOT_VERIFIED` بدل صنع نسبة صفر أو مئة مضللة.

## خطوات التنفيذ التالية للمناهج

1. تنزيل **الفهارس والعناوين فقط** من المصدر الوزاري المسموح، لا نسخ الكتب كاملة دون ترخيص.
2. بناء سجل `دولة / العام / الصف / الفصل / الكتاب / الوحدة / اسم الدرس / الصفحات / رابط المصدر / نوع المطابقة / حالة مراجعة المعلم`.
3. مقارنة هذه العناصر بدروس الإنتاج عبر استعلامات **قراءة فقط** دون إدخال نتائج أو تعديلها، وفصل الإثراء عن المواضيع الرسمية.
4. لا تُرقِّ أي درس إلى «مطابق كامل» إلا بعد فحص عنوانه ومحتواه وموضوعه وطبعة الكتاب وتاريخ مراجعة بشرية.
5. إنشاء أو إصلاح حزمة المحتوى الأصلية، واختبار صحة الأسئلة والنص العربي وحقوق المصدر، ثم فتح PR مستقل للاستيراد الآمن.
6. تُكرر العملية للصفين الثاني والثالث ثم الدول الأخرى، مع الحفاظ على الأولوية للصفوف 1–3.

### ملفات التدقيق الجديدة

- تُرفق نتيجة التدقيق في GitHub Actions مع تقرير الحزم السابق.
