# ضاديوم — توحيد أسماء البحث القريبة | 29 أكتوبر 2026

## الهدف
ربط اسم العلامة التعريفي الرسمي **ضاديوم (Dadyoom)** ببعض الصيغ التي يكتبها الزوار بطريقة طبيعية وقابلة للاكتشاف، **دون وعد بترتيب معين أو ضمان تصحيح كل خطأ إملائي**.

## التنفيذ
1. اسم الموقع في بيانات `WebSite` المنظمة يظل **ضاديوم** فقط. `alternateName` يحتوي، وفق ترتيب الأولوية، على `Dadyoom` و`ضاضيوم` و`داديوم` و`ضاديو` و`Dadyoum` وأخيرًا `dadyoom.com`.
2. يظهر شرح مختصر ومفيد للزائر عن الاسم العربي الصحيح والصيغ القريبة في الصفحة الرئيسية؛ وتضيف صفحة «عن ضاديوم» شرحًا أكثر تفصيلًا.
3. عنوان الصفحة الرسمي والوصف التعريفي يظلان متمحورين حول **ضاديوم**، دون إنشاء صفحات رقيقة لكل خطأ إملائي، أو حشو كلمات، أو شراء روابط، أو استعمال كلمات لا علاقة لها بالمنصة.
4. اختبارات المصدر تراجع الصيغ وترتيبها وتفردها.
5. لا تضاف `meta keywords` لأنها لا تحل مشكلة ترتيب Google.

## قيود مهمة
- Google ينشئ ويختار اسم الموقع ويصحح أخطاء الاستعلام بخوارزمياته؛ `alternateName` مجرد إشارة، وليس ضمان ظهور عند كل صيغة.
- لا يمكننا تأكيد فهرسة Google من GitHub وحده؛ الوصول إلى Google Search Console المتصل بتطبيق GSC Wizard يعيد `payment_required` (الخدمة الخارجية فقط). يمكن استخدام Google Search Console الأصلي مجانًا.
- يجب إصلاح نشر Cloudflare (issue #46) كي تصل تغييرات GitHub إلى الموقع الحقيقي، ثم طلب إعادة الزحف للصفحة الرئيسية و`/about` وإرسال خريطة الموقع.
- مصدر التعليمات: https://developers.google.com/search/docs/appearance/site-names
- سياسة عدم حشو الكلمات: https://developers.google.com/search/docs/essentials/spam-policies
