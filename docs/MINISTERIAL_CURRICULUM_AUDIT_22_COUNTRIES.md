# Dadyoom Ministry-to-Lesson Audit Engine — أداة تدقيق المناهج الوزارية

## هوية المهمة
محرّك **مستقل، قراءة فقط، يرفض إعلان الكمال عند الشك**. يتعامل مع 22 دولة × الصفوف 1–12 × الفصلين (528 نطاقًا أساسيًا)، ومع الصف 13 **اختياريًا فقط** إذا ثبت وجوده رسميًا. يدعم فروع التعليم المختلفة بواسطة \`track\` مع عدم مساواة المسار الأدبي بالعلمي أو الفني. لا يؤلف نصًا أو سؤالًا ولا ينشر درسًا أو يغير محاولة طالب؛ **فريق ضاديوم هو الذي يصحح بعد مراجعة المصدر**.

لا يكفي عدد الصفحات أو الدروس أو الأنشطة لإعلان 100%. المفهوم الصحيح للـ100%: موافقة فهرس الكتاب والطبعة؛ مراجعة كل النصوص والمفردات والتشكيل؛ مراجعة علمية ولغوية وتربوية للأسئلة ومفاتيحها؛ مهارات القراءة والكتابة والاستماع والتحدث؛ 5 ألعاب حقيقية لكل درس عند اشتراطها؛ تصحيح صوتي وإتاحة؛ تجربة الواجهة على حسابات المستخدمين؛ واعتماد بشري موثق يثبت صحة الدرس. النصوص الأصلية التي ألّفها ضاديوم للإثراء **ليست النص الوزاري الرسمي** حتى لو تطابق اسم الدرس.

## الملفات والمكوّنات
- \`data/ministerial-audit/official-source-registry-2026-2027.json\`: قائمة الدول الـ22 ورابط الدخول الوزاري المؤكد عند توافره. لا تدّعي القائمة وجود فهرس موثّق لأي صف لم يُفحص بعد.
- \`scripts/ministerial-audit.mjs\`: المحرك الجامع والمقارن، يمكنه فحص المصدر الرسمي على نطاقات HTTPS معتمدة، ثم إخراج JSON وتقرير Markdown، أو قراءة قاعدة ضاديوم في وضع read-only.
- \`scripts/ministerial-extract-pdf.mjs\`: تفريغ PDF رسمي إلى **مرشحات نصية صفحة صفحة**، مع بصمة SHA-256 وأرقام الصفحات وإنذارات عند وجود مسح ضوئي أو تعذر استخراج. هذه ليست شهادة صحة لغوية؛ لا يمكن إغفال مراجعة الصور والتشكيل والجدول.
- \`lib/ministerial-audit/engine.mjs\`: قواعد مقارنة صارمة لا تقبل المرادفات التلقائية والاختلافات الغامضة بوصفها تطابقًا.
- \`tests/ministerial-audit.node.test.mjs\`: اختبارات التكرار والتطابق الخاطئ والنقص ومصادر غير رسمية والسنة الدراسية والفصول والصف 13.
- \`.github/workflows/ministerial-curriculum-audit.yml\`: يمنع أي اختبارات تُظهر اعتمادًا للمناهج بلا مستندات رسمية.

## التشغيل

تدقيق النطاقات كلها **بلا حقائق وزارية مفترضة** — النتيجة المتوقعة BLOCKED لغياب فهارس معتمدة:
\`\`\`bash
node scripts/ministerial-audit.mjs --out _audits/ministerial
\`\`\`

تسجيل توافر المواقع الحكومية الموجودة في القائمة فقط (لا يصنف محتواها تلقائيًا على أنه الكتاب الصحيح):
\`\`\`bash
node scripts/ministerial-audit.mjs --probe-official-portals --out _audits/ministerial
\`\`\`

استخراج PDF **محلي بعد تنزيله من الوزارة عبر مصدر معتمد**:
\`\`\`bash
node scripts/ministerial-extract-pdf.mjs --pdf /safe/local/ministry-book.pdf --source-url https://example.edu.gov/book.pdf --out _audits/ministerial/pdf-candidates.json
\`\`\`
تُجرى مراجعة مرئية للصفحات على أيدي المراجعين، ولا تُرفع النسخة الكاملة من الكتب إلى GitHub دون إذن النشر.

قارن مع نسخة محلية مختصرة من الدروس (تضم فقط بيانات غير حساسة):
\`\`\`bash
node scripts/ministerial-audit.mjs --platform /safe/local/dadyoom-lessons.json --official-dir /safe/local/verified-manifests --year 2026-2027 --out _audits/ministerial
\`\`\`

قراءة قاعدة الإنتاج فقط (على جهاز موثوق، **السر لا يدخل GitHub أو ملف تقرير أو متصفح**):
\`\`\`bash
NEXT_PUBLIC_SUPABASE_URL=https://PROJECT.supabase.co SUPABASE_SERVICE_ROLE_KEY=SECRET node scripts/ministerial-audit.mjs --live --official-dir /safe/local/verified-manifests --out _audits/ministerial
\`\`\`
يعتمد التصدير على SELECT لأعمدة غير حساسة من الجداول، **ولا يقرأ \`correct_answer\` ولا \`answer\`**. يلزم مفتاح الخدمة متاحًا خارج كود المستودع؛ انظر سجلات البيئة وتحقق من عدم تسجيله.
ويمكن تفعيل \`--strict\` ليخرج البرنامج برمز 2 إذا لم تُثبت المطابقة الكاملة؛ أو \`--include-grade13\` لنطاقات الصف 13 عند إثبات وجوده.

## صيغة الفهرس الرسمي المعتمد
يُحفظ كل ملف JSON بنطاق واحد **دولة/صف/فصل/مسار/سنة** في مجلد \`--official-dir\`. لا يُضاف إلا بعد مراجعة الكتاب الحقيقي:
\`\`\`json
{
  "country": "BH",
  "grade": 1,
  "semester": 1,
  "track": "general",
  "academicYear": "2026-2027",
  "subject": "arabic",
  "source": {
    "url": "https://www.edunet.bh/...",
    "documentType": "textbook",
    "edition": "2026-2027",
    "sha256": "SHA-256 of the ACTUAL downloaded textbook, 64 hex characters",
    "extractionStatus": "reviewed",
    "retrievedAt": "2026-10-31",
    "reviewedAt": "2026-10-31",
    "reviewedBy": "actual reviewer identity"
  },
  "units": [
    {
      "title": "عنوان الوحدة كما ظهر في المصدر",
      "lessons": [
        { "title": "العنوان الرسمي المنقول بعد الفحص", "page": 3 }
      ]
    }
  ]
}
\`\`\`
القيم التوضيحية ليست مطابقة حقيقية ويجب تغيير كل عنوان ورقم صفحة ورابط وبصمة باسم الملف الرسمي الصحيح؛ لا تخترع أبدًا مصدرًا أو SHA ولا توقع بالنيابة عن المعلم.

## طريقة إصدار قائمة الإصلاح
1. أولوية المرحلة الأولى: الصف 1، ثم 2، ثم 3 لجميع الدول قبل أي إعلان نهائي.
2. إجبار كل نطاق على مصدر رسمي حديث وروابط/بصمة وتاريخ وسنة وفصل وصف ومسار، ومرجع صفحة لكل درس.
3. مقارنة \`unitTitle+title\` داخل الدولة والصف والفصل والمسار. الاسم القريب **مرشح للتفتيش** فقط، وليس تطابقًا. لا تُفسر غياب فهرس الوزارة بأنه إكمال.
4. وسم \`OFFICIAL_LESSON_MISSING_OR_RENAMED\` و\`PLATFORM_LESSON_NOT_IN_OFFICIAL_TOC\` و\`DUPLICATE_...\` واختلاف السنة أو الصف والفصل و\`PLATFORM_SEMESTER_UNASSIGNED\` كلٌّ مستقلاً.
5. مراجعة المحتوى الفعلي والسياق والنحو والإملاء والمفردات والتشكيل والإرشادات والأنشطة والصوت والألعاب والأسئلة والإجابات على المعلم؛ لا توجد خوارزمية أو نظام تهجئة يضمن صحة كل كلمة عربية بلا مراجعة متخصصة.
6. يتسلّم المطور قائمة عيوب محددة مع معرف الدرس والسبب ومرجع الصفحة، ويعدّل بنفسه بعد مراجعة تربوية؛ يمنع النشر التلقائي والاستبدال الخفي لنص الوزارة بمادة مستحدثة.
7. يُعاد التحقق في بيئة الاختبار والحساب الحقيقي، ثم يسجل المختص واعتماد النسخة والنص؛ لا تنتج درجة 100% بلا كل البوابات.

## أدلة مصادر البداية (ليست فهارس معتمدة)
- البحرين: \`https://www.edunet.bh/Econtent/BooksGuide\` و\`https://www.edunet.bh/Econtent/LessonsGuide\` يشيران إلى عام 2026–2027؛ يحتاج كل ملف داخلهما إلى استخراج ومراجعة.
- فلسطين: \`https://moe.edu.ps/pal-books\` بوابة للكتب؛ تبيّن أن بعض الروابط المتاحة تحمل سنة **2024**، فلا يجوز اعتمادها تلقائيًا طبعة 2026–2027.
- السعودية: موقع الوزارة \`https://www.moe.gov.sa/ar/knowledgecenter/eservices/Pages/ien.aspx\` يذكر «عين»؛ الإرشادات القديمة لا تثبت طبعات السنة الجديدة.
- بقية الدول: ما زالت بحاجة إلى فهرسة المصادر الحكومية والتحقق من الطبعات؛ لا تضع رابطًا غير موثق لمجرد ملء خانة.

**هام**: القائمة \`data/curriculum-audits/grades123-308-lesson-source-review-queue-20261031.json\` هي **فجوة معيار الأنشطة فقط**. لا تختزل تدقيق المناهج في تلك الـ308؛ يجب فحص الدروس المنشورة **كلها** وبحث الرسمي غير الموجود أصلًا في قاعدة البيانات، بما في ذلك الوحدات والصفوف العليا.


## نتيجة أول جرد إنتاجي حقيقي في 31 أكتوبر 2026

استُعلمت قاعدة بيانات ضاديوم **قراءة فقط** عبر علاقة الدول ← المناهج ← الصفوف ← الوحدات ← الدروس، ولم يتغير أي سجل. الجرد موجود على GitHub:
\`data/ministerial-audit/platform-all22-grades1-13-production-inventory-20261031.json\`.

- **22 دولة**؛ **266 خانة دولة×صف** مسجلة فعلًا؛ من 1 إلى 12 لجميع البلدان، وصف **13 مسجل في موريتانيا وتونس فقط** (98 و22 درسًا، على التوالي). لا يوجد إلى الآن دليل مستقل يؤكد أن ترقيم 13 يمثل سنة ثانوية إضافية رسمية؛ يجب مطابقة الهيكل التعليمي قبل اتخاذ قرار إبقائه أو إعادة ربطه.
- **8,259 سجل درس** في الصفوف المسجلة كلها؛ **8,156 منشورة** و**103 مسودات** (93 البحرين، 7 عُمان، 3 اليمن).
- عدد الدروس التي يظهر بها \`source_pdf_url\` هو **3,315**؛ وجود الرابط في السجل لا يثبت صحة نسخه وسنته ومرجع صفحته، وغيابه لا يثبت وحده خطأ محتوى الدرس.
- هذه أرقام مخزون فقط. لا تعني أن كل فهرس دولة/فصل اكتمل في ضاديوم، فالمصدر الوزاري لم يُقارن بعد واحدًا بواحد.

**حالة مرشحة مستقلة تحتاج فحص المصدر البصري والطبعة:** نص فهرس ملف «لغتنا الجميلة — الرزمة التعليمية» الصادر عن الوزارة الفلسطينية عام **2024** يتضمن بحسب الاستخراج «الفراشة والنخلة» (صفحة مطبوعة 100)، في حين أن السجل المنشور من ضاديوم للصف الأول/الفصل الثاني لعام **2026–2027** اسمه «الفراشة والنحلة». هذه **ليست مخالفة مثبتة**: قد يكون الاستخراج غير دقيق، أو حصل تغيير رسمي لاحق، ولا يجوز تصحيح أو إعادة تسمية السجل قبل الحصول على طبعة العام الحالي ومراجعة الصورة. ملخص الحالة:
\`data/ministerial-audit/cases/PS-G1-2024-candidate-farasha-title-20261031.json\`.

**تغطية مداخل البحث الوزارية الحالية:** تم إثبات ارتباط مواقع حكومية أو بوابات حكومية لـ16 دولة (ليس معناه توثيق كتبها)، ولا تزال 6 دول بلا رابط موثّق في سجل الأداة: العراق، السودان، الصومال، جيبوتي، جزر القمر، موريتانيا. ويظل **0 ملف فهرس 2026–2027 للكتب العربية معتمدًا للمقارنة النهائية** حتى توفير نسخة وثائقية موقعة ومفحوصة؛ ولذلك من الصحيح هندسيًا أن يُخرج المحرك حالة \`BLOCKED\`، لا نسبة جاهزية وهمية.
