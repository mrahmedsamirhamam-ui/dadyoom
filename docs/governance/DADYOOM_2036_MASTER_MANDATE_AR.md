# ضاديوم 2036 — الميثاق الأعلى المعتمد للتطوير (نسخة مراجعة)

> **حالة المستند:** توثيق متطلبات المالك في GitHub للمراجعة. لا يعني الدمج أو التفعيل في الإنتاج، ولا يثبت تحقق أي معيار.

## الهوية والرؤية
**ضاديوم – بيت العربية الرقمي**: نظام تشغيل عالمي لتعليم العربية وقياس النمو الحقيقي للمتعلمين، وربط أطراف العملية التعليمية بأمان ودقة وذكاء.

**الرؤية:** أن تصبح ضاديوم المرجع العالمي الأول لتعليم العربية وقياس نمو متعلميها وتحسين نتائجهم الفعلية.

**الرسالة:** تمكين كل متعلم من التقدم الحقيقي بغض النظر عن العمر أو الدولة أو المنهج أو اللغة الأم، عبر البيانات والذكاء الاصطناعي والتكيف والتقييم المستمر.

**السؤال الحاكم:** ما الذي أصبح المتعلم قادرًا على فعله باللغة العربية اليوم مقارنة بالأمس؟

## المستفيدون والنطاق
الطالب، المعلم، ولي الأمر، المدرسة، شبكة المدارس، الإدارة التعليمية، وزارة التعليم، العرب في المهجر، غير الناطقين بالعربية، المؤسسات التعليمية الدولية.

المستهدف: المناهج الرسمية في الدول العربية الـ22، Cambridge وOxford وIB وIGCSE والمنهج الأمريكي، والعربية للناطقين بها ولغير الناطقين بها. لا تُدّعى تغطية أو مواءمة رسمية بلا دليل ومراجعة مصدر.

## DACF — إطار ضاديوم للكفايات اللغوية العربية
المجالات الأربعة عشر:
1. القراءة
2. الفهم القرائي
3. المفردات
4. الكتابة
5. الإملاء
6. النحو
7. الصرف
8. التعبير الكتابي
9. التعبير الشفهي
10. الاستماع
11. المحادثة
12. البلاغة
13. التذوق الأدبي
14. التفكير النقدي اللغوي

لكل كفاية فرعية: مستوى، مؤشرات أداء، سلوك ملاحظ، آلية قياس، مستويات إتقان، فجوات، علاج، إثراء، ومعايير قبول. لا ازدواج في احتساب الأدلة المتداخلة.

## ملف النمو وAGI
لكل متعلم: مستوى بداية، مستوى حالي، إتقان، معدل نمو، قوة وضعف، فجوات، أنشطة مقترحة، وتوقع مستقبلي **فقط بعد التحقق العلمي من صلاحية التنبؤ**.

**AGI — Arabic Growth Index**: التحسن الفعلي، سرعة التحسن، استقراره، جودته، واستمرارية التعلم. المؤشر **قيد التصميم وليس مقياسًا مُعايرًا أو مثبتًا**. يجب توثيق تكافؤ صور الاختبار والصدق والثبات والعدالة وفترات عدم اليقين قبل نشر ادعاءات النمو.

التقييم: تشخيصي قبل التعلم، تكويني أثناءه، ختامي بعده، وتقييم نمو عبر الزمن. بنك الأسئلة يتطلب صورًا متكافئة لكل مهارة ومستوى.

## التكيف والألعاب وضاد
التكيف يغير نوع النشاط والصعوبة والتسلسل: علاج وتدريب وتبسيط عند التعثر، وتحديات وإثراء ومشروعات عند التقدم.

الألعاب المرتبطة بكفايات DACF: تحدي الإملاء، سباق الكلمات، صياد الأخطاء، أبطال القراءة، مغامرات النحو، بناء الفقرة، مختبر المفردات. النقاط والشارات للإتقان والنمو والاستمرارية وتحقيق الأهداف، لا للنقرات.

**ضاد AI**: للطالب شرح وتبسيط وتدريب وتصحيح وخطة تعلم؛ للمعلم اختبارات وأنشطة وأوراق عمل وتحليل وتدخلات؛ لولي الأمر تقارير وأنشطة منزلية؛ للمدرسة تحليل الأداء والمخاطر المبكرة. التقييمات المؤثرة في الطالب تتطلب ضوابط جودة ومراجعة بشرية مناسبة.

## لوحات المعلومات
- الطالب: المهارات، النمو، المهام، الإنجازات، خطة التحسين.
- المعلم: أداء الطلاب، النمو، المهارات المتعثرة، التدخلات.
- ولي الأمر: تقدم الأبناء المرتبطين، القوة والضعف، التوصيات.
- المدرسة: أداء الصفوف والمعلمين والنمو والمهارات الحرجة.
- الوزارة: مؤشرات وطنية ومقارنات وفجوات ونمو المدارس ببيانات مجمعة وضوابط خصوصية.

## الأدوار والأمن أولًا
Student / Teacher / Parent / School Admin / Network Admin / Ministry Admin / Super Admin.

المتطلبات الإلزامية: منع الترقية الذاتية، عزل المدارس والطلاب، تقييد أولياء الأمور بأبنائهم المرتبطين، حماية الإجابات النموذجية والدرجات وواجهات API وقواعد البيانات، سجلات تدقيق غير قابلة للتلاعب، نسخ احتياطي واستعادة مجربة.

اختبارات: Broken Access Control، IDOR، JWT Validation، Role Escalation، Injection، Tenant Isolation، Session Security، واختبارات RLS بصلاحيات حقيقية في بيئة معزولة.

**NO-GO** عند وجود خطر حرج/مرتفع، أو فشل اختبار إلزامي، أو غياب دليل التحقق. لا يُعوّض المؤشر الأمني المرتفع عن بوابة فاشلة.

## دورة التطوير
تحليل ← تصميم ← مراجعة أمنية ← تطوير بفرع مستقل ← اختبارات أمنية ووظيفية ← بيئة تجريبية ← قياس أثر ← موافقة المالك ← نشر تدريجي ← مراقبة ← تحسين. لا دمج أو نشر بلا موافقة صريحة.

## الممنوعات
لا ميزة بلا أثر تربوي، أو بلا قياس، أو خارج DACF، أو تعرّض البيانات للخطر، أو يتعذر التحقق من نجاحها.

## مؤشرات النجاح
النمو اللغوي المثبت، الإتقان، سرعة التحسن، جودة التدخلات، رضا المعلمين والأسر، واستمرارية التعلم. أعداد الدروس والاختبارات والملفات ليست مؤشرات النجاح الرئيسية.

## خارطة الطريق الملزمة بالبوابات
1. **P0:** الأمن المعزول، منع ترقية الأدوار، حماية الدرجات والإجابات، عزل المدارس.
2. **P1:** اختبارات DACF ببيانات اصطناعية والتحقق من القياس.
3. **P2:** مواءمة موضوعات البحرين للصفوف 1–3 بالمهارات، مع توثيق المصدر والقبول وإثبات النمو.
4. **P3:** ملف النمو اللغوي وAGI.
5. **P4:** التعلم التكيفي.
6. **P5:** ضاد AI.
7. **P6:** الألعاب التعليمية.
8. **P7:** باقي الدول العربية والمناهج الدولية.

## القانون الأعلى
لا يُنفّذ أي قرار تقني أو تربوي أو تجاري إلا إذا (1) حسّن تعلم العربية، (2) حافظ على أمن المستخدمين، (3) أمكن قياس أثره بالبيانات.

**معيار النجاح 2036:** كم متعلمًا أثبتت ضاديوم تحسن مستواه الحقيقي في العربية بالأدلة والبيانات؟
