# مختبر هرم ماسلو للاحتياجات الإنسانية — ضاديوم

**المسار:** `/labs/maslow`

## الغرض
نشاط إثرائي تفاعلي مجاني باللغة العربية، خارج مسار المناهج الرسمية، لفهم الاحتياجات الإنسانية وعلاقتها بالمواقف الصفية والدافعية إلى التعلم. مبني على **العرض التعليمي الشائع بخمسة مستويات** الذي يُنسب إلى أبراهام ماسلو.

## المحتوى الفعلي
- هرم تفاعلي بألوان هادئة وخمسة مستويات: احتياجات الجسم، الأمان، الحب والانتماء، التقدير، وتحقيق الذات.
- عند اختيار أي مستوى: شرح عربي ومفردات وأمثلة مدرسية، واقتراح تصرف للمعلم، ومهمة قصيرة للكتابة.
- نشاط مواقف يربط مواقف مدرسية افتراضية بالمستوى الأنسب مع تغذية راجعة تفسيرية.
- لا تخزين، ولا درجة مدرسية أو بيانات شخصية، ولا خدمات خارجية مدفوعة.

## حدود تربوية وأخلاقية
- هذا **تبسيط تعليمي**، لا قاعدة نفسية تشخيصية مثبتة لكل الأشخاص. ليست المستويات بالضرورة سلّمًا خطيًا؛ قد تتداخل الحاجات وتختلف أولوياتها عبر الأفراد والثقافات والظروف.
- لا يُطلب من الطفل أو الطالب الكشف عن ظروف منزلية أو صحية أو مالية. الأمثلة افتراضية؛ لا تضع تقييمًا لحاجات الطلاب أو فئات نفسية داخل ملف الطالب.
- مسارات الدعم المدرسي والحماية النفسية والرفاه ليست بديلًا عنها هذه الوحدة. إذا كان هناك أذى أو تنمّر، يراجع المتعلم مسؤولًا موثوقًا.
- لا يُعلن أي تغطية وزارية أو اكتمال منصة أو نشر حي بهذا النشاط.

## تحقق مطلوب قبل الدمج والنشر
- `npm run test:run -- tests/maslow-lab.test.ts`
- `npx tsc --noEmit`
- `npm run lint`
- `npm run build`
- فحص على هاتف وعلى لوحة مفاتيح والمتصفح، وتأكد من عمل التنقل بين المستويات وتغذية راجعة النشاط دون إرسال بيانات.
