# إعادة بناء كتب التلوين — تجربة تربوية مضبوطة (30 أكتوبر 2026)

**الحالة: PILOT_NOT_FOR_RETAIL**. أُنتجت نسختان جديدتان A4 من 20 صفحة لكل منهما، بما في ذلك الغلاف ودليل الاستخدام. في كل نسخة **18 نشاطًا تعليميًا**، لا 160 صفحة مكتملة. النسخ القديمة موقوفة لأن كثرة الصفحات لا تعوض رسومات غير واضحة أو تدريبات غير مرتبطة بالأهداف.

## المستندات الإنتاجية المحفوظة
الملفات الأصلية القابلة للطباعة، وWord لدليل الأسرة والمعلم، ومصدر Python القابل لإعادة التوليد، والصور والرسوم، وملف JSON لتفاصيل كل درس، وCSV للقياس، جميعها محفوظة في مكتبة المالك على:
`/مؤلفات ضاديوم/إعادة بناء كتب التلوين/`

**لا تَعُدّ ملف JSON الموجود في المستودع دليلًا على وجود جميع رسومات الكتاب أو نشره.** هو سجل تربوي مفتوح للمراجعة فقط.

## مسار «الحروف والكلمات»
تهيئة اليد (رأسي/أفقي/منحنٍ/متعرج) → الصورة والحديث عنها → الصوت في بداية «أرنب» → التمييز بين أ، ب، ت → التعرف على البيت والباء → التفاحة والتاء → ربط الصور بالحروف → إنتاج كلمات جديدة.

## مسار «الاكتشاف ومهارات الحياة»
الملاحظة واللغة في نبات مألوف → احتياجات النمو والمسؤولية → الماء والشرب والغسل والترشيد → أجزاء البيت والسلوك الآمن والتعاون → المشاة والمحاكاة الآمنة لعبور الطريق → نقل فكرة الحفاظ على البيئة إلى سياق جديد.

## بروتوكول قبول كل صفحة (لا يسمح بتمرير إخفاق جوهري)
- هدف لغوي أو معرفي واحد قابل للملاحظة، ومسار تدرج ملائم لطفل حقيقي.
- رسم أصلي معبر بوضوح عن الكلمة/الموقف، مساحات تلوين ملائمة، لا بدائل مجردة ولا صور مستهلكة متكررة.
- النشاط يَطلب من الطفل التسمية والملاحظة والتفكير أو التتبع أو التعبير؛ وليس تلوينًا بلا معنى.
- فحص أي تلميح غير مقصود إلى الإجابة، أو أكثر من إجابة صحيحة دون توضيح.
- مساحات وتوجيهات مناسبة للمستوى الحركي، دون فرض قبضة واحدة على القلم.
- تدقيق عربي RTL ورسم الحرف واتجاه حركة اليد، مع تجنب الخلط بين اسم الحرف وصوته.
- مراعاة فروق الاستعداد والاحتياجات، والقدرة على الإجابة شفهيا قبل الكتابة.
- تقويم قصير للاستقلال ونقل المهارة؛ ويفضل تجربة محدودة متنوعة قبل الإطلاق.
- مراجعة حقوق الرسوم والنطاق الرسمي للروابط؛ **لا QR غير منشور**.

## نشر الإنتاج
النسختان الأوليتان لم تُدمجا في الموقع، ولم يُنشر QR جديد، ولم يُعتمد إعادة بناء كامل الـ320 صفحة، ولم تُستبدل أغلفة «التعليم بين التقليد والعصرنة» أو «هندسة التفكير والتعلّم».

## تطبيق الميثاق على بقية المشاريع (مسؤوليات مرجعية، ليست ادعاء تنفيذ)
- **المناهج في 22 بلدًا:** مطابقة النسخ الرسمية وتدقيق الأهداف والمحتوى لكل درس، لا الاعتماد على العدد وحده.
- **«أنت المؤلف»:** انتقال الصورة → الخيال → التخطيط → كتابة القصة → المراجعة → النشر بموافقة مسؤول عند مشاركة عمل الأطفال.
- **البودكاست والمناظرة:** دليل أصالة، حقوق استخدام، لغة وحجة، وموافقة نشر.
- **مدارس ضاديوم الدولية:** الصلاحيات والتسجيل والربط الفعلي والتوافر وقواعد حماية بيانات الطلاب قبل الجاهزية.
- **الكتب التربوية:** الأغلفة الأصلية ثابتة واسم المؤلف «أحمد سمير حمام»؛ الترجمتان تحتاجان تدقيق مطابقة نصية مستقلًا.
- **مشروع التلفزيون:** بحث وعتاد واستعادة آمنة قبل أي تفليش، لا دليل على إقلاع Android لمجرد وجود كود.
- **ممول:** الأمان والشروط والحقوق والامتثال قبل التسويق.
- **DALMIF:** معيار ضاديوم المقترح غير معتمد خارجيًا؛ الادعاءات العالمية تتطلب تحكيمًا ودراسة أثر ومقارنة مستقلة.
