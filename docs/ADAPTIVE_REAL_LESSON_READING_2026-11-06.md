# مسارات شرح الدروس الفعلية في ضاديوم — 2026-11-06

**الهدف:** فائدة عامة للطالب داخل صفحة الدرس المنشور نفسها دون كتابة قصة بديلة، تغيير الأهداف، إعادة ترتيب المنهج أو كشف مفاتيح التصحيح.

## نطاق هذه الحزمة الصغيرة

- ملف الصفحة: app/lessons/[id]/page.tsx — يستبدل عرض الشرح النصي الثابت بمكوّن شرح تعليمي قابل للاختيار، مع **الحفاظ على عرض الشرائح والأسئلة والأنشطة والمفردات وتسجيل التقدم كما كانت**.
- المكوّن: features/lessons/components/LessonExplanationPaths.tsx.
- الخوارزمية: lib/adaptive-goal-paths/grounded-lesson-reading.mjs — تقسّم نص الدرس المنشور في وضع البداية **دون حذف أو إعادة صياغة أو اختراع كلمة واحدة**، ويمكن إعادة جمع المقاطع للحصول على النص الأصلي حرفيًا.
- **الافتراضي:** مسار التقدم يعرض النص المنشور **كاملًا منذ أول تحميل للصفحة** لتجنب فقدان فهرسة محركات البحث أو تغيير تجربة القراءة دون اختيار الطالب.
- مسار البداية: أجزاء صغيرة، السابق/التالي، مساعد قراءة صوتية يعتمد دعم المتصفح، مع هدف تعليمي يختاره الطالب من قائمة الأهداف المسجلة فعليًا.
- مسار التقدم: المحتوى الأصلي الكامل ببطاقاته وعناوينه مع التركيز على هدف محدد.
- مسار التحدي: شرح الدرس الحقيقي كاملًا وكتابة تفسير بدليل من النص في ذاكرة جلسة المتصفح فقط؛ مراجعة ذاتية لا تصحح ولا تخزن تلقائيًا.

## ضمانات

1. لا تعدّل جداول Supabase أو الأسئلة أو مفتاح الإجابة أو API التصحيح أو أسماء الطلبة.
2. لا تدّعي أن مسارات القراءة تشخيص ذكاء اصطناعي أو تمنح درجات؛ التقييم الأصلي الموجود بعد الشرح يظل هو المرجع، مع تحقق الأدوار والسياسات الخادمية كما هي.
3. الأهداف المعروضة تؤخذ حرفيًا من سجل الدرس؛ إذا لم يُسجّل هدف لا ننشئ هدفًا افتراضيًا.
4. هذه طريقة عرض، وليست شهادة بأن الدرس يطابق طبعة الوزارة 2026–2027 أو أن أيًا من الدول الـ22 وصل إلى 100%.
5. لا بيانات حساسة أو كتابة محلية دائمة أو استدعاءات خارجية جديدة؛ إجابة التحدي تبقى مؤقتة داخل صفحة المستخدم.
6. يمنع اعتبار الاستماع نجاحًا إذا لم يدعم المتصفح الصوت العربي. الرسالة لا تعد بتوافر صوت غير موجود.
7. لا روابط خارجية أو تكلفة API؛ لا تغيير Cloudflare أو فرع الإنتاج.
