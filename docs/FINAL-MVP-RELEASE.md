# ضاديوم — الإغلاق النهائي للـMVP

بوابة الإطلاق النهائية لا تعتمد على وجود اسم الدولة فقط؛ بل تفرق بين:

- المنصة والمحرك: جاهزان لاستقبال الدول والصفوف عبر Curriculum Packs.
- سجل الدول العربية: 22 دولة.
- المحتوى الموثق الموجود حاليًا: يُحسب من الحزم الفعلية فقط.
- تسجيل Google: يجب أن ينجح فعليًا قبل النشر.
- ضاد: يجب أن يعيد ردًا حقيقيًا من API الإنتاج المحلي.
- الطالب والمعلم وولي الأمر والمدرسة والإدارة: تخضع لحماية الأدوار.
- الأسرار وملفات IDE وSupabase temp لا تُرفع إلى Git.
- لا يتم Commit/Push إلا بعد نجاح TypeScript وESLint والاختبارات وProduction Build وSmoke Test.

إضافة منهج جديد لاحقًا هي عملية محتوى:
مصدر موثوق ← Curriculum Pack ← تحقق ← Dry Run ← اعتماد ← استيراد.
ولا تتطلب إعادة برمجة ضاديوم لكل دولة.


## حالة الإغلاق التشغيلية — سبتمبر 2026

- Android Native 1.0.2 موقّع ومنشور مع Qwen Offline وGoogle OAuth Deep Link وNative TTS وUpdater.
- Dadyoom Core متاح للدول العربية الـ22 من الصف الأول إلى الثاني عشر.
- المطابقة الوطنية الرسمية تظل Fail-Closed ولا تُعلن مكتملة بمجرد وجود Core أو عدد من الدروس.
- تجربة Plus للمستخدم الجديد يوم واحد؛ الاشتراك المدفوع لا يُصنف Live حتى ينجح Payment E2E حقيقي.
- iOS يبنى Native في CI؛ تثبيته على جهاز حقيقي يتطلب توقيع Apple حقيقي.
- مولد الفيديو عند الطلب ليس شرط إطلاق حاليًا ولا يُعرض كميزة مكتملة ما دام مزودوه غير مستقرين.
