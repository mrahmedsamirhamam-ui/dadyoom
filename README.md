
# ضاديوم — بيت العربية الرقمي

ضاديوم منصة عربية تعليمية مبنية بـ Next.js وTypeScript وSupabase، وتهدف إلى جعل تعلّم العربية أكثر وضوحًا وتفاعلًا وتخصيصًا للطالب، مع أدوات عملية للمعلم وولي الأمر والمدرسة.

**الموقع الرسمي المعتمد للفهرسة:** https://dadyoom.com/  (النطاق السابق `https://dadyoom.dpdns.org` ما زال متاحًا لجلسات المستخدمين وروابط قديمة).

الاسم الرسمي: **ضاديوم (Dadyoom)**، وقد يُكتب في البحث أيضًا: **ضاضيوم** أو **داديوم**.

## النطاق الأساسي

- مناهج ودروس منشورة من المسار الرسمي: الدولة ← المنهج ← الصف ← الوحدة ← الدرس.
- مهارات القراءة والكتابة والاستماع والتحدث مع تدريبات فعلية ومسار تكيفي.
- قاموس سياقي ورفيق تعليمي ذكي «ضاد».
- تقدم الطالب، التوصيات، خطة التعلم، التقييمات، XP والمستويات والشارات والتحدي اليومي.
- لوحة المعلم والفصول والطلاب وإنشاء الدروس وتحرير المحتوى والأهداف والمفردات والأسئلة والوسائط.
- بوابات ولي الأمر والمدرسة وتقارير المتابعة والربط الآمن بالحسابات.
- لوحة إدارة للمناهج والدروس ومراجعة المحتوى المدعوم بالذكاء الاصطناعي.

## متغيرات البيئة

يحتاج المشروع إلى متغيرات Supabase وGemini المناسبة في `.env.local`. لا تُحفظ المفاتيح السرية داخل Git. استخدم `NEXT_PUBLIC_SITE_URL` للدومين.

## النطاق الرسمي الجديد والفهرسة المستقرة — أكتوبر 2026

- اشترى المؤسس `dadyoom.com` وربطه بالـCloudflare Worker `dadyoom`، وأثبتت صورة المتصفح نجاح تسجيل الدخول بحساب الإدارة على `https://dadyoom.com/admin`.
- `dadyoom.com` هو **canonical** لصفحات التسويق والمناهج العامة. تبقى جلسات الحسابات ومسارات OAuth محصورة بنطاقها الأصلي. تحويل الصفحات العامة القديمة فقط `308` لا يشمل روابط رموز OAuth أو صفحات الإدارة المحمية.
- مصدر `/sitemap.xml` الوحيد المعتمد هو `app/sitemap.ts`: الصفحات العامة + الدول الـ22 + الصفوف التي لها دروس مفهرسة + الدروس المؤهلة بفهرس `seo_indexable_lessons_fast` + الدورات المنشورة فعلًا. يحتفظ `/sitemap-brand.xml` بالروابط الثلاثة على نطاق `.com` للتوافق، لكن `robots.txt` يعلن **الخريطة الجامعة فقط**؛ ممنوع إدراج صفحات المسودات أو الحسابات أو بطاقات الكتب غير التعليمية.
- الاسم الرسمي هو **«ضاديوم | Dadyoom — بيت العربية الرقمي»**، وصيغ البحث الطبيعية «ضاضيوم/داديوم/ضاديو/Dadyoum» مرادفات نصية في الصفحة والبيانات المنظمة، وليست صفحات وهمية أو روابط منفصلة في sitemap. «ضاد» اسم المساعد الذكي؛ ليس اسمًا بديلًا رسميًا للمؤسسة.
- **معيار جودة نتائج Google:** الصفحات التي يبدأ محتواها بشرح مستورد عام `يتناول هذا الدرس موضوع «` أو يظل بها `مدخل OCR غير محسوم` لا تدخل خريطة الدروس المفهرسة حتى تُستكمل مراجعتها. تبقى منشورة للطلاب إذا كانت منشورة أصلًا، وتظهر في قائمة مراجعة الإدارة دون تحويل المصدر إلى شهادة اعتماد. ترحيل `20261016160913_exclude_unresolved_ocr_and_boilerplate_from_seo.sql` يحافظ على فهرس SEO المادي وتحديثه دون توقف.
- **تمييز SEO بين الدرس والنطاق:** يعتمد فهرس `seo_indexable_lessons_fast` على `seo_indexable_lessons` المحمي بـ`security_invoker`، ولا يفهرس عقد النطاقات المنهجية ومراجع الكتب كما لو كانت دروسًا تعليمية. التغيير مسجل في `supabase/migrations/20261016153314_exclude_curriculum_scope_records_from_seo_index.sql`، ويستعمل `REFRESH MATERIALIZED VIEW CONCURRENTLY` مع الفهرس الفريد القائم. عدد الصفحات المؤهلة متغير ولا يمثل شهادة مطابقة رسمية؛ لا تعاود تقديم Sitemap بسبب نقصان عدد الروابط.
- Google Search Console: **تحقق من ملكية `sc-domain:dadyoom.com` أو خاصية URL prefix `https://dadyoom.com/`، ثم أرسل `https://dadyoom.com/sitemap.xml` مرة واحدة بعد نجاح النشر**. لا تطلب فهرسة آلاف الصفحات يدويًا، ولا تعتبر sitemap وعدًا بترتيب جوجل. خاصية Search Console الموصولة عبر GSC Wizard غير متاحة للاستخدام حاليًا بسبب قيود التجربة/الاشتراك؛ لا تفعّل دفعًا.
- راجع في إصدار الإنتاج: `https://dadyoom.com/` و`/robots.txt` و`/sitemap.xml` و`/sitemap-brand.xml` و`/api/deploy/version`، ثم تقرير `SEO Production Gate` لنفس Git SHA. فشل مزامنة النشر أو اختلاف canonical يمنع إعلان النجاح.
- تستمر حماية بيانات الطلاب وSupabase/Google OAuth وسياسة المدفوعات صفرية؛ لا تغيير في صلاحيات المستخدمين أو محتوى الكتب بسبب النقل.

فحص كود القطع الآمن (قراءة فقط):
```bash
node scripts/check-domain-migration-ready.mjs
```

 `.com` لا يثبت اكتمال المناهج أو أهلية AdSense تلقائيًا، ولا يتضمن أي اشتراك أو تفعيل Paddle Live.

- خانة «شكوى» مستقلة عن «مقترح»، وملاحظات الإدارة خاصة، والرد العام ظاهر فقط لصاحب التذكرة. متطلبات الخصوصية والأطفال وإذن التواصل باقية. قاعدة بيانات الدعم محمية والخادم يتحقق من الهوية عبر getUser.

- **استوديو هرم المعلم:** /interactive-lab/pyramid/teacher لتعديل الأهداف والأسئلة والإجابات والمراجعة والتلميحات مع معاينة وتصدير مسودة JSON محلي؛ لا نشر تلقائي للمحتوى ولا تصحيح آلي للنص الإبداعي.
- كلا التطويرين يعتمدان مستودع الإنتاج الحالي، وتبقى المناهج والدروس الرسمية أولوية. لا اعتماد للإطلاق قبل فحوص TypeScript وVitest وvinext وSmoke Tests فعلية.

## إغلاق نقص أهداف تعليمية في دروس البحرين — 2026-10-19

- **تنفيذ فعلي في قاعدة الإنتاج:** عولجت ثلاثة دروس منشورة من الصف الأول / الجزء الثاني («الدرس الثالث: حرف ك»، «الدرس الرابع: حرفا ف وأ»، «الدرس الثامن: حرفا خ وذ»)، بإضافة ثلاثة أهداف أدائية أصلية متمايزة لكل درس دون إعادة نشره أو تغيير نصه أو أسئلته أو مصدره.
- **التحقق بعد التنفيذ:** يوجد 21 درسًا منشورًا في هذا النطاق، وأصبح `missing_objectives=0` و`three_or_more_objectives=21`. تحفظ وصفة تحديث البيانات الحذرة في `data/curriculum-completeness/bahrain-grade1-sem2-three-letter-objectives-20261019.sql` لتتبع المصدر والنسخة.
- **ليست شهادة اعتماد للفصل الثاني:** تبقى هذه الدروس موسومة `official-book-unscheduled`؛ نشر خطة الفصل الثاني الحالية أو مطابقة فهرس كتاب مستقل شرط منفصل. تقرير `bahrain-book-completeness-2026-2027.json` لا يزال يعتبر `COMPLETE_BOOK=0` لأن مطابقة TOC الرسمية 1:1 لم تثبت.
- **المسودات التي تحتاج معالجة:** كشف فحص مباشر 62 مسودة غير منشورة في الصفوف الأساسية 2–9 (الفصل الأول)، بينها عناوين غير سليمة مستخرجة من OCR. لا تُرفع إلى `published` دون إعادة بناء العنوان الصحيح وإثبات رابط المصدر ومراجعة بشريّة؛ يجب عدم مضاعفة عدد الدروس المنشورة بتلك المسودات.
- يستمر ترتيب التنفيذ: مراجعة مصدر TOC → إصلاح عناوين الدروس الحقيقية الناقصة → تحرير محتوى وأهداف وأنشطة أصلية → اختبار تربوي ثم نشر مدروس؛ لا اختلاق دروس لمجرد زيادة العدّاد.
