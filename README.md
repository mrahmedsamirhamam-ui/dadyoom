
# ضاديوم — بيت العربية الرقمي

ضاديوم منصة عربية تعليمية مبنية بـ Next.js وTypeScript وSupabase، وتهدف إلى جعل تعلّم العربية أكثر وضوحًا وتفاعلًا وتخصيصًا للطالب، مع أدوات عملية للمعلم وولي الأمر والمدرسة.

**الموقع الرسمي:** https://dadyoom.dpdns.org/

الاسم الرسمي: **ضاديوم (Dadyoom)**، وقد يُكتب في البحث أيضًا: **ضاضيوم** أو **داديوم**.

## النطاق الأساسي

- مناهج ودروس منشورة من المسار الرسمي: الدولة ← المنهج ← الصف ← الوحدة ← الدرس.
- مهارات القراءة والكتابة والاستماع والتحدث مع تدريبات فعلية ومسار تكيفي.
- قاموس سياقي ورفيق تعليمي ذكي «ضاد».
- تقدم الطالب، التوصيات، خطة التعلم، التقييمات، XP والمستويات والشارات والتحدي اليومي.
- لوحة المعلم والفصول والطلاب وإنشاء الدروس وتحرير المحتوى والأهداف والمفردات والأسئلة والوسائط.
- بوابات ولي الأمر والمدرسة وتقارير المتابعة والربط الآمن بالحسابات.
- لوحة إدارة للمناهج والدروس ومراجعة المحتوى المدعوم بالذكاء الاصطناعي.

## التشغيل المحلي

```bash
npm install
npm run dev
```

## متغيرات البيئة

يحتاج المشروع إلى متغيرات Supabase وGemini المناسبة في `.env.local`. لا تُحفظ المفاتيح السرية داخل Git. استخدم `NEXT_PUBLIC_SITE_URL` للدومين العام عند النشر، و`SUPABASE_SERVICE_ROLE_KEY` للعمليات الخادمية الموثوقة فقط مثل رفع وسائط المعلم.

## تجهيز نطاق ضاديوم المستقل

الهدف المبدئي `dadyoom.com`؛ **التجهيز ليس شراءً أو انتقالًا**. يبقى
`https://dadyoom.dpdns.org` هو نطاق الإنتاج وcanonical الفعلي إلى أن
يثبت امتلاك النطاق الجديد، وربطه، واختبار تسجيل الدخول والفهرسة.

تحقق من الجاهزية دون تعديل حسابات أو DNS:

```bash
node scripts/check-domain-migration-ready.mjs
```

تسلسل القطع المعتمد عند امتلاك النطاق رسميًا:

1. مراجعة توافر `dadyoom.com` والسعر النهائي في Cloudflare Registrar واعتماد التكلفة قبل الشراء.
2. إضافة منطقة `dadyoom.com` النشطة إلى حساب Cloudflare الصحيح، ثم ربط Worker `dadyoom` عبر **Custom Domain**؛ لا تحذف أو تستبدل رابط الإنتاج الحالي.
3. اختبار HTTPS و`/api/deploy/version` وجميع الأدوار، Google OAuth وSupabase redirect allow-list وملفات الارتباط وجلسات الطلاب على العنوان الجديد.
4. بعد إثبات سلامة النسخة الجديدة، ضبط `NEXT_PUBLIC_SITE_URL` و`DADYOOM_INDEXNOW_SITE` في البيئة المعتمدة، وتعديل اختبار SHA في Workflow؛ تحقق من robots وsitemap وcanonical قبل تحويل أي رابط دائم.
5. بعد اعتماد النطاق الرئيسي وفهرسته، إعداد تحويلات 301 من النطاق القديم بحذر مع إبقاء إمكانية الرجوع؛ لا تبدّل DNS أو canonical مبكرًا.

التغيير إلى `.com` لا يثبت اكتمال المناهج أو أهلية AdSense تلقائيًا، ولا يتضمن أي اشتراك أو تفعيل Paddle Live.
