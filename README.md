
# ضاديوم — بيت العربية الرقمي

ضاديوم منصة عربية تعليمية مبنية بـ Next.js وTypeScript وSupabase، وتهدف إلى جعل تعلّم العربية أكثر وضوحًا وتفاعلًا وتخصيصًا للطالب، مع أدوات عملية للمعلم وولي الأمر والمدرسة.

**الموقع الرسمي:** https://dadyoom.dpdns.org/

**اسم المنصة:** ضاديوم (Dadyoom) — بيت العربية الرقمي. قد يكتب بعض الزوار الاسم «ضاضيوم» أو «داديوم» أو «ضاديو»؛ وتشير هذه الصيغ إلى الموقع الرسمي نفسه.

## النطاق الأساسي

- مناهج ودروس منشورة من المسار الرسمي: الدولة ← المنهج ← الصف ← الوحدة ← الدرس.
- مهارات القراءة والكتابة والاستماع والتحدث مع تدريبات فعلية ومسار تكيفي.
- قاموس سياقي ورفيق تعليمي ذكي «ضاد».
- تقدم الطالب، التوصيات، خطة التعلم، التقييمات، XP والمستويات والشارات والتحدي اليومي.
- لوحة المعلم والفصول والطلاب وإنشاء الدروس وتحرير المحتوى والأهداف والمفردات والأسئلة والوسائط.
- بوابات ولي الأمر والمدرسة وتقارير المتابعة والربط الآمن بالحسابات.
- لوحة إدارة للمناهج والدروس ومراجعة المحتوى المدعوم بالذكاء الاصطناعي.

## تنبيه تدقيق الإنتاج — 21 أكتوبر 2026

يحتوي Supabase على 22 دولة و8,307 سجلات درس منشور من أصل 8,379، لكن هذه الأرقام **لا تساوي اكتمال المناهج الرسمية**. فحص الجودة المباشر بعد إصلاح سجلين كشف 596 درسًا منشورًا بلا أسئلة في جدول `questions`، و514 درسًا بأقل من ثلاثة أهداف، و1,193 درسًا بلا مفردات مسجلة؛ وهذه مؤشرات فحص لا أحكام على صلاحية كل درس. يوجد في المستودع حاليًا ملف حزمة مناهج فعلية واحد للبحرين (الصف الأول/الفصل الأول)، بينما تتوافر محتويات إضافية في قاعدة البيانات ولم تُقارن جميعها بفهرس الوزارة. لم يُتحقق من الموقع الحي بهذه الجولة.  أُضيفت كذلك 9 أسئلة مشروحة لثلاثة دروس إثرائية بالصف الثامن في قاعدة الإنتاج مع تحقق بنيوي، دون ادعاء أنها أسئلة الكتاب المدرسي.تفاصيل التدقيق في `docs/CURRICULUM-OPERATIONS.md`؛ يميّز `npm run curriculum:coverage` بين فحص الحزم واكتمال الفهارس الرسمية، ويدعم `--require-all-countries` كشرط لوجود حزم لكل الدول، لا دليل مطابقة رسمية.

## مختبر الحروف — نموذج تفاعلي قابل للمراجعة (2026-10-21)

**الحالة الفعلية (2026-10-21):** دُمج التنفيذ في `main` عبر [PR #28](https://github.com/mrahmedsamirhamam-ui/dadyoom/pull/28)، واجتاز TypeScript وESLint واختبارات Vitest وNext.js build واختبار Chrome للهاتف بعرض 390px، كما نجحت معاينة Netlify. **لم يُتحقق بعد من نشر النسخة المدمجة على النطاق الإنتاجي، ولم تُجر مراجعة صفية بشرية.**

- المسار في الشيفرة: `/labs/letters`، مع رابط من الصفحة الرئيسية عند نشر الإصدار، ودون تغيير التصميم الأصلي.
- ثلاثة مستويات (تأسيس، بناء، تحدٍّ)، وفي كل مستوى ثلاث كلمات أصلية؛ التفاعل: تحديد الحرف الأول ← ترتيب بطاقات الحروف ← اختيار المعنى ← مثال في جملة.
- مشهد حروف متحركة ووعاء ذهني باستخدام CSS فقط؛ يوقف الحركة لمن يفضل تقليلها، ويعمل باللمس ولوحة المفاتيح.
- زر نطق اختياري عبر Web Speech API عند توفر الصوت العربي على جهاز المستخدم، مع بقاء الكلمات مكتوبة دائمًا. جودة الصوت تختلف حسب الجهاز.
- احتساب نقاط **الإجابة الصحيحة من المحاولة الأولى** وإرشادات تصحيحية؛ حالة الجلسة داخل الذاكرة فقط، **دون تخزين على الخادم ودون ادعاء ارتباط بنتائج المناهج الرسمية**.
- فحوص ناجحة بالفعل: `npx tsc --noEmit` و`npm run lint` و`npm run test:run` و`npm run build`، و`node scripts/smoke-letter-lab.mjs` على Chrome بعرض هاتف 390px. لا تحل الاختبارات الآلية محل مراجعة معلم واختبار متعلم حقيقي.
- **الخطوات المؤجلة:** ربط الدروس الرسمية بعد مراجعة المعلم، وتجربة طلاب واقعية، وقياس الإتقان، ثم تقرير حفظ نتائج التقدم بأمان داخل الحساب؛ لا يُنسب هذا إلى ميزة مكتملة حاليًا.
- الميزانية صفر؛ لا توجد واجهات AI مدفوعة أو خدمة رسوميات مدفوعة.

## مقترحات التطوير — عالم حكايات ضاديوم (2026-10-16)

**الحالة: مقترح معتمد للنظر في التنفيذ، وليس ميزة منفذة.** الفكرة: «كل درس حكاية، وكل حكاية مغامرة، وكل مغامرة تعلّم». الهدف تعليم العربية بالقصص المصورة والتفاعل والتغذية الراجعة، وفق المنهج الرسمي والفروق الفردية، مع الحفاظ على شعارَي «اللغة العربية أسهل في ضاديوم» و«ضاديوم تزرع حب اللغة العربية في قلب الطالب».

### قرار تطويري معتمد — الاستفادة من إعلان AyahPath (2026-10-18)

**الحالة:** اعتماد التوجه التربوي والتقني وتوثيقه فقط؛ **لم تُبنَ ميزة جديدة ولم تُختبر أو تُنشر** بموجب هذا القرار. لقطة إعلان AyahPath مرجع لفكرة شخصية كرتونية وحوار وقصة قصيرة، ولا تثبت أداة الإنتاج أو خصائص التطبيق الداخلية. يمنع نسخ شخصيات الإعلان أو هويته أو السيناريوهات المحمية.

**الفلسفة:** تحويل الفيديو القصير من محتوى يشاهده الطالب إلى موقف تعليمي `مشهد قصصي ← اختيار/سؤال ← تفاعل صوتي أو كتابي ← تغذية راجعة ← نشاط علاجي/إثرائي ← قياس إتقان`، مع الحفاظ على هوية «ضاديوم — بيت اللغة العربية» والشعار «ضاديوم تزرع حب اللغة العربية في قلب الطالب».

**المواصفات المعتمدة للتطوير:**
- شخصيات وحوارات عربية أصلية ملائمة للعمر، بنصوص مضبوطة ومراجعة لغويًا وتربويًا، وتنوع قصصي دون تقليد الإعلان.
- حلقات قصيرة وحكايات متفرعة يختار الطالب مجرياتها، أسئلة أثناء القصة، قراءة أدوار، وتوظيف المفردات والتراكيب في سياق حيّ.
- دعم مستويات صعوبة متدرجة، وإتاحة تفريغ نصي للصوت، وتحكم بسرعة التشغيل، وبدائل للمتعلمين الذين لا يستطيعون استخدام الصوت.
- ربط كل حكاية بمرجع الدرس الرسمي `country / curriculum / grade / unit / lesson / learning_objectives`؛ عدم اختراع درس أو ادعاء اكتمال منهج لم يُتحقق منه.
- استخدام وحدات الدروس والأسئلة والتقييم والتقدم والتعلم التكيفي الحالية ما أمكن، وتخزين نتائج المهارات بدل الاقتصار على مدة مشاهدة الفيديو.
- في استوديو المعلم: اقتراح سيناريو ومشاهد ومهام وأسئلة، **مع اعتماد المعلم قبل النشر**. عدم اتخاذ قرارات تقويمية عالية الأثر تلقائيًا.
- قيود سلامة للأطفال: تقليل جمع البيانات، صلاحيات مناسبة للأدوار، عدم عرض التسجيلات أو بيانات التعلم للعموم، وعدم حفظ صوت الطفل افتراضيًا بلا حاجة وموافقة مناسبة.

**مسار التنفيذ المجاني أولًا:**
1. نموذج مرئي تفاعلي خفيف للهاتف، باستخدام رسومات أو صور أصلية مرخصة مع حوار مكتوب/صوتي وأسئلة في نقاط توقف؛ لا اشتراط لتوليد فيديو AI لكل تشغيل.
2. تقييم استخدام `Rive` الموجود ضمن اعتماديات المشروع للحركة الثنائية، وتجريب `Three.js / React Three Fiber` فقط إذا كانت ثلاثية الأبعاد تحقق فائدة واضحة بعد قياس الأداء والتراخيص.
3. تجربة `Web Speech API` للنطق عند دعم الجهاز واللغة، مع ملفات صوتية بديلة؛ لا افتراض لتساوي جودة النطق العربي. فحص تراخيص محركات تحريك الشفاه وجودتها العربية قبل اعتمادها.

**أول تجربة قبول:** قصة تفاعلية أصلية لـ«حرف الشين» في درس رسمي بحريني موثق، تتضمن المشهد والصوت/النص وسؤال تعرف على «شجرة» وإعادة المحاولة والتغذية الراجعة، ثم نشاط ختامي مع تسجيل الإتقان. بعدها يراجعها معلم ويختبرها طلاب على الهاتف قبل تعميم قالب الحروف الـ28، ثم ربطه بباقي الدروس الرسمية للدول الـ22.

## مقترح تطوير — رحلة الباحث الصغير ومهارات الاستقصاء (2026-10-16)

### الهدف
تحويل البحث من حفظ إجابات إلى رحلة تعلّم قائمة على التساؤل والاستكشاف والتحليل والتجريب والإبداع والتحسين، مرتبطة بأهداف الدروس الرسمية وبمستوى الطالب وفروقه الفردية.

### رحلة الطالب (ست مراحل)
1. أتساءل: أصوغ سؤالًا مناسبًا للدرس.
2. أستكشف: أجمع معلومات وأدلة من مصادر مناسبة وآمنة.
3. أفكر: أقارن وأحلل وأفسر.
4. أجرب: أختبر الفرضيات حين يلائم النشاط، وأوثق الملاحظات.
5. أبدع: أكتب تقريرًا أو أصمم مشروعًا وأعرض نتائجي.
6. أتطور: أتلقى تغذية راجعة وأراجع عملي.

**مثال:** درس إنبات البذور: سؤال عن أثر الهواء أو الحرارة، تجربة مناسبة للعمر، تسجيل النتائج، الاستنتاج. وفي العربية: استقصاء المفردات أو النصوص والظواهر اللغوية.

## Dadyoom Arabic Vision — Arabic OCR verification concept

**Status:** proposed independent component, not implemented or released. Inspired by Arabic OCR proofreading workflows, without copying any third-party implementation or proprietary material.

**Mission:** extract text from authorized Arabic documents, preserve page structure and right-to-left reading order, and verify extracted text against original page images with a human reviewer.

**Core workflow:** authorized upload and rights declaration -> image cleanup -> OCR provider abstraction (prefer zero-cost/local where feasible) -> Arabic text/line segmentation -> side-by-side image and text review -> low-confidence highlights -> human corrections and audit trail -> searchable accessible exports (UTF-8 text, DOCX, PDF with text layer as supported).

**Arabic QA:** hamza, ta marbuta/ha, alif maqsura/ya, diacritics, punctuation, numerals, ligatures, mixed Arabic-English lines, tables, headings, footnotes, page order and RTL layout. Never silently change source text or invent missing words. Record uncertainty and reviewer approval.

**Integrations (proposed only):** official curriculum lesson indexing, teacher worksheet editor, school forms with strict access control, publishing manuscripts, research source archives. Keep product independent with documented API and repository; do not ingest copyrighted textbooks without permission or collect student data without a lawful basis and safeguards.

**Success criteria to test:** character and word error rates on licensed Arabic samples, layout accuracy, reviewer time per page, accessibility, privacy/security, and cost per page. Human acceptance gate before publication.

**Priority and IP:** do not delay current platform stability or verified official curricula/lessons; document original design and source licenses, third-party OCR model terms, contributions and evidence of authorship in the private IP dossier. Zero-cost default; no paid APIs without approval.

**الحالة:** متطلب تربوي معتمد للتطوير والاختبار؛ توثيقه لا يعني تطبيقه برمجيًا أو توافره في جميع الدروس المنشورة.

### دورة التعلم داخل درس القراءة

1. **قبل القراءة:** تنشيط المعرفة السابقة، وتوضيح هدف القراءة، وتوقع محتوى النص.
2. **أثناء القراءة:** تدريب مناسب على القراءة، وتوضيح المفردات من السياق، وتحديد الفكرة الرئيسة والعلاقات بين الأفكار.
3. **بعد القراءة:** أسئلة للفهم المباشر والاستنتاجي والنقدي والتعبير بلغة الطالب، مناسبة لعمره وصفه.
4. **التشخيص:** فصل مؤشرات دقة القراءة والطلاقة عن الفهم والتعبير؛ تحديد المهارة التي تشير إليها إجابات الطالب دون إصدار تشخيص طبي أو تصنيف دائم للطفل.
5. **التدخل:** شرح بديل وتدرج في الصعوبة وأنشطة فردية مناسبة؛ إبقاء دور المعلم في المراجعة والتعديل.
6. **إعادة التحقق:** نص موازٍ أو مهمة جديدة تقيس نقل المهارة، مع تسجيل الفرق بين القياسين وعدم الاكتفاء بإعادة السؤال نفسه.

## الرسالة التعليمية العالمية — العربية للناطقين وغير الناطقين بها (2026-10-18)

**الحالة: رؤية ومواصفات تعليمية معتمدة للتطوير، وليست إعلانًا عن ميزات منفذة أو منشورة.**

ضاديوم — **بيت اللغة العربية** — لا تكتفي بعرض الدروس. رسالتها جعل العربية لغة محبوبة ومفهومة ومستخدمة في التفكير والإبداع والتواصل، للناطقين بها وغير الناطقين بها، مع إبقاء إتقان المتعلم معيار النجاح الحقيقي.

> لا نعلّم العربية ليحفظها المتعلم، بل ليحبّها ويفهمها ويتحدث بها ويفكر ويبدع من خلالها.

### المسارات التعليمية

1. **للناطقين بالعربية:** استكمال الدروس الفعلية في المناهج الرسمية؛ البحرين أولًا ثم الدول الـ22، بمطابقة المصادر والأهداف والمحتوى، ثم دعم النحو والصرف والقراءة والبلاغة والكتابة والفهم والتعبير.
2. **للناطقين بغير العربية:** مسار مستقل لتعلّم العربية لغة ثانية/أجنبية، يبدأ بتحديد الاحتياج والمستوى، الصوتيات والأبجدية والتواصل اليومي، ثم كفايات الاستماع والتحدث والقراءة والكتابة على مستويات متدرجة؛ دون ربطه قسرًا بالصفوف الوطنية أو الادعاء بشهادة معيارية غير مثبتة.

### ما يميّز درس ضاديوم

- **موقف وتمثيل أصلي:** صورة/مشهد أو فيديو قصير/قصة/حوار يثير الفضول ويربط المهارة بالحياة، لا مشاهدة سلبية فقط.
- **اكتشاف وتطبيق:** يتعرف المتعلم على الظاهرة اللغوية، يشرحها بلغته، ينتج مثالًا، ويطبقها في موقف مختلف.
- **التكيّف والفروق الفردية:** أنشطة علاجية وإثرائية ومسارات صوتية ونصية وألعاب متنوعة، تختلف باختلاف السن والمستوى والهدف لا باختلاف الجنسية وحدها.
- **ذكاء اصطناعي مساعد:** شرح وتلميح ومراجعة لغوية ومحادثة ونطق عند تحقق الجودة والموافقة والخصوصية؛ دور المعلم محفوظ في التقييم والاعتماد.
- **تحقق لا انطباع:** قياس الفهم والاستعمال والانتقال لمهمة جديدة والتقدم بين القياسات، بدل مساواة حفظ الإجابة أو مشاهدة الفيديو بالإتقان.

**مثال تطبيق: درس الحال.** في مشهد قصصي لطالب يطرق باب المنزل، نعرض «عاد الطالبُ مسرورًا»، ثم نسأل: «كيف عاد الطالب؟»، ونتدرج إلى تمييز الحال وصاحبه وتكوين جمل من مواقف جديدة. للناطق بغير العربية نبدأ بفهم معنى الجملة والاستعمال السياقي قبل المصطلحات النحوية المكثفة.

**ضوابط ثابتة:** تصحيح لغوي وتربوي، محتوى أصلي أو مرخص، قابلية استخدام على الهاتف، إتاحة بدائل نصية/صوتية، حماية بيانات الأطفال، مراجعة المعلم، وعدم الادعاء بالمطابقة الرسمية أو توافر ميزات لم تُختبر. كل قصة تتصل بمهارة ودرس حقيقي عندما تكون ضمن المناهج الرسمية.

**الأولوية الفعلية:** إنهاء المحتوى الرسمي الناقص والتحقق من جودته واستقرار المنصة قبل التوسع الثقيل في الفيديو/الألعاب؛ ثم اختبار نماذج واقعية لمسار غير الناطقين والمواقف التمثيلية وتوسيعها بناءً على نتائج موثقة. التمويل الافتراضي صفر؛ لا دفع أو استهلاك API مدفوع بلا موافقة. تبقى مشاريع المؤسسة مستقلة ويمكنها التكامل عبر واجهات واضحة.

**المراجع الداخلية:** `docs/VISION.md` للرؤية، و`docs/PRODUCT-CONTRACT.md` لمتطلبات المنتج، و`ROADMAP.md` للأولويات.

## ميثاق ضاديوم للجودة والثقة — 2026-10-19

**الهوية:** ضاديوم — بيت اللغة العربية؛ ليست للطلاب وحدهم، بل بيت للطالب والمعلم وولي الأمر والمدرسة والباحث والمؤلف والمتخصص، وللناطقين بالعربية وغير الناطقين بها. تتكامل تحت مظلتها مجالات التعليم والتأهيل والبحث والابتكار والإنتاج المعرفي والشراكات، مع استقلال المشروعات تشغيليًا وتقنيًا.

- علمية: عربية سليمة، ومناهج موثوقة، ومحتوى مطابق للمستوى ومراجع قبل النشر.

- أخلاقية ومهنية: حماية خصوصية الأطفال والمستخدمين، شفافية حالة الإنجاز، استقبال الشكاوى والمقترحات ومعالجتها.

**ضوابط عملية قابلة للقياس:** سجل تغطية المناهج والدروس والتحقق من مطابقتها، اختبارات قبول لكل دور وعلى الهاتف، مراجعة لغوية وتربوية بعينات موثقة، قياس إتقان المهارات قبل الأنشطة وبعدها، توثيق الأعطال وزمن معالجتها، ومراجعات مستقلة دورية. لا تُعلَن نسبة اكتمال بلا أدلة فحص.

**الأولوية التنفيذية:** استكمال دروس البحرين الرسمية والتحقق من عمل التعلم الذاتي والتقويم وحفظ التقدم أولًا، ثم التوسع لبقية الدول الـ22. الأفكار الجديدة لا تؤخر هذا المسار.
